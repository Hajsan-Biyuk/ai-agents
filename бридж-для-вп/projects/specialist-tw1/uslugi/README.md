# Курсы и услуги (specialist.cm17867.tw1.ru)

Тип записи **«Курсы и услуги»** (`uslugi`, адреса `/uslugi/<название>/`) и таксономия **«Направления»** (`napravlenie`) созданы
в админке ACF («Типы записей» / «Таксономии»), в теме не регистрируются.

## Что где

| Что | Где |
|---|---|
| Шаблон услуги | `theme-src/single-uslugi.php` |
| Перечень (страница 70, `/услуги/`) | `theme-src/page-70.php` |
| Общие функции вывода блоков | `theme-src/hp-ks.php` |
| Стили | `verstka/css/uslugi.css` |
| Группа полей «Курс или услуга» | ACF, ключ `group_ks_service`, описание в `acf/ks_schema.json` |
| Группа полей «Перечень курсов и услуг» | ACF, ключ `group_ks_list`, страница 70 |
| 301-редиректы `/<название>/` → `/uslugi/<название>/` | `mu-plugins/hp-uslugi-redirects.php` → `wp-content/mu-plugins/` |
| Контент услуг до переноса (HTML боевого сайта) | `source/prod-pages-before.json` |
| Данные, разобранные по полям | `acf/final.json` |
| Значки плиток и картинки документов | `media/` |

## Поля услуги

Вкладки «Баннер» (H1 из трёх частей, подзаголовок, стоимость, фото), «Для перечня услуг» (значок, короткое описание) и
«Содержимое» — гибкое поле `ks_sections` с блоками: заголовок, текст, список, карточки, этапы, изображения, видео.
Каждый заголовок раздела (крупный) начинает новый раздел на странице.

## Как это строилось

Контент с боевого сайта специалист-082.рф (только чтение) разобран `acf/parse.py` по блокам с проверкой, что ни одно слово не потеряно,
`acf/build_data.py` собирает данные и оптимизирует картинки, `acf/build_ks.py` готовит одноразовый установщик
(создание типа, групп, медиа, перенос страниц, заполнение полей). Скрипты — справочные: в путях указан рабочий каталог
сессии, установщик на сервере после запуска заменён заглушкой.

## Откат

Старый HTML остался в `post_content` каждой записи. Чтобы вернуть страницы: сменить `post_type` обратно на `page`
(`set_post_type($id, 'page')`) и удалить `mu-plugins/hp-uslugi-redirects.php`.
