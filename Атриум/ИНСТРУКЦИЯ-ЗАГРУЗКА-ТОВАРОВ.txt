1. КАК ЭТО РАБОТАЕТ (кратко)
--------------------------------------------------------------------------------

На сервере настроен автоматический импорт товаров.

  Вы кладёте Excel-файл прайса в специальную папку (inbox)
       ↓
  Система сама читает файл, проверяет данные и загружает товары на сайт
       ↓
  Готовый отчёт сохраняется в папку reports
  Обработанный файл переносится в папку processed

ВАЖНО:
  • Импорт НЕ удаляет товары с сайта — только создаёт новые и обновляет
    существующие по артикулу.
  • Если в файле ошибки — товары на сайт НЕ попадут, файл уйдёт в карантин.
  • Один и тот же прайс повторно не обрабатывается, пока вы не замените
    файл в inbox на новую версию.


--------------------------------------------------------------------------------
2. КУДА ЗАХОДИТЬ НА СЕРВЕРЕ
--------------------------------------------------------------------------------

Сайт: https://atriumceramic.sheer26.ru

Доступ к файлам — через панель хостинга Beget (файловый менеджер) или SFTP.
Логин и пароль выдаёт администратор проекта.

Корневая папка импорта на сервере:

  /home/s/sheer26/atriumceramic.sheer26.ru/import/

Структура папок (что вам нужно знать):

  import/
  ├── inbox/              ← СЮДА кладёте новые прайсы
  │   ├── artkera/        ← плитка Арткера
  │   ├── rgw/            ← душевые RGW
  │   └── santehcentr/    ← Центр Сантехники
  ├── processed/          ← сюда уходят успешно обработанные файлы (архив)
  ├── quarantine/         ← сюда попадают файлы с ошибками
  └── reports/            ← отчёты о каждой загрузке

Папку import не переименовывать и не переносить.


--------------------------------------------------------------------------------
3. ОБЩИЙ ПОРЯДОК ЗАГРУЗКИ (для любого поставщика)
--------------------------------------------------------------------------------

ШАГ 1. Подготовьте прайс
  • Формат: Excel (.xls или .xlsx)
  • Кодировка: UTF-8 (кириллица читается нормально)
  • Обязательные колонки: Артикул, Наименование, Цена
  • Для корректного размещения в каталоге желательна колонка «Путь»
    (цепочка разделов сайта). Если «Путь» нет — товар попадёт в раздел
    по умолчанию (см. раздел 4 по каждому поставщику).

ШАГ 2. Очистите папку inbox нужного поставщика
  • Откройте import/inbox/{artkera|rgw|santehcentr}/
  • Удалите старые файлы, если они там остались с прошлой загрузки
  • В inbox должны лежать ТОЛЬКО файлы текущей загрузки

ШАГ 3. Загрузите новый прайс
  • Скопируйте файл(ы) в соответствующую папку inbox
  • Дождитесь окончания загрузки (в файловом менеджере файл должен
    полностью появиться, размер совпадать с оригиналом)

ШАГ 4. Дождитесь автоматической обработки
  • Импорт запускается автоматически каждые 30 минут
  • Обычно после загрузки файла ждите от 5 до 35 минут
  • При большом прайсе (десятки тысяч позиций) обработка может занять
    1–3 часа

ШАГ 5. Проверьте результат
  • Откройте import/reports/ — найдите свежий файл отчёта
    (имя вида 2026-07-10_164245_santehcentr.json)
  • Если файл ушёл в processed/ — загрузка прошла успешно
  • Если файл в quarantine/ — была ошибка, читайте REASON.txt (раздел 7)

ШАГ 6. Проверьте сайт
  • Откройте 2–3 товара на сайте: название, цена, раздел, фото
  • При необходимости в админке Bitrix: Настройки → Производительность
    → Очистить кеш

--------------------------------------------------------------------------------
5. ЧТО ПРОИСХОДИТ ПРИ ИМПОРТЕ
--------------------------------------------------------------------------------

Для каждого товара в прайсе система делает одно из действий:

  СОЗДАТЬ   — артикула ещё нет на сайте → появится новая карточка
  ОБНОВИТЬ   — артикул уже есть → обновятся цена, название, наличие,
              характеристики, раздел (по данным из прайса)
  ПРОПУСТИТЬ — строка не прошла проверку (пустой артикул и т.п.)

Фотографии:
  • Для НОВЫХ товаров фото скачиваются с URL из прайса (если колонка
    «Фото» заполнена)
  • Для существующих товаров фото обычно не перезаписываются

Цены:
  • Розничная цена из прайса → тип цены BASE на сайте
  • Оптовая цена рассчитывается автоматически (тип OPT)

Бренды:
  • Если бренд из прайса есть на сайте — товар привяжется к нему
  • Если бренда нет — он создаётся автоматически


--------------------------------------------------------------------------------
6. КАК ЧИТАТЬ ОТЧЁТ
--------------------------------------------------------------------------------

После обработки в import/reports/ появляется JSON-файл, например:
  2026-07-10_164245_santehcentr.json

Откройте его в блокноте. Главные поля:

  status          — итог обработки:
                    imported          = успешно загружено на сайт
                    imported_with_errors = загружено, но были мелкие ошибки
                    quarantine        = файл в карантине, на сайт не попал
                    dry_run_only      = только проверка, без записи

  dry_run.created — сколько НОВЫХ товаров будет/было создано
  dry_run.updated — сколько существующих обновлено
  dry_run.errors_count — ошибок при проверке (должно быть 0)

  log             — пошаговый журнал (партии, количество товаров)

Пример успешного отчёта:
  "status": "imported"
  "dry_run": { "created": 203, "updated": 1164, "errors_count": 0 }

Если errors_count больше нуля — файл, скорее всего, ушёл в карантин.


--------------------------------------------------------------------------------
7. КАРАНТИН — ЧТО ДЕЛАТЬ ПРИ ОШИБКЕ
--------------------------------------------------------------------------------

Если прайс попал в import/quarantine/{поставщик}/:

  1. Откройте файл REASON.txt в этой папке — там написана причина
  2. Откройте report.json — там список конкретных ошибок
  3. Исправьте прайс (или попросите того, кто его готовит)
  4. Удалите файлы из quarantine (или оставьте как архив ошибки)
  5. Положите исправленный файл снова в inbox

Типичные причины карантина:

  • Слишком много ошибок в файле (битые строки, пустые артикулы)
  • Слишком много НОВЫХ товаров за один раз (защита от кривого файла)
  • Ошибки при проверке на сайте (неверный путь раздела, дубликаты)
  • Неверный формат файла (не Excel, повреждённый файл)

При любой ошибке карантина товары на сайт НЕ меняются.


--------------------------------------------------------------------------------
8. ПРОВЕРКА НА САЙТЕ ПОСЛЕ ЗАГРУЗКИ
--------------------------------------------------------------------------------

Чек-лист для редактора:

  [ ] В import/processed/ лежит ваш файл (или папка с датой обработки)
  [ ] В import/reports/ отчёт со status = imported
  [ ] errors_count = 0
  [ ] На сайте открываются 2–3 новых/обновлённых товара:
        — правильное название
        — актуальная цена
        — товар в нужном разделе каталога
        — у новых товаров есть фото (если в прайсе были ссылки)
  [ ] В разделе /info/brands/ у новых брендов есть кликабельная ссылка
  [ ] При странном отображении — очистить кеш в админке Bitrix


--------------------------------------------------------------------------------
9. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

В: Я загрузил файл, но ничего не происходит.
О: Подождите до 35 минут (cron каждые 30 мин). Проверьте, что файл лежит
   именно в inbox/{поставщик}/, а не в корне import или public_html.
   Убедитесь, что файл НОВЫЙ (заменили старый — система увидит изменение).

В: Можно ли загрузить прайсы двух поставщиков одновременно?
О: Да. Положите файлы в разные папки inbox (artkera, rgw, santehcentr).
   Каждый обработается отдельно.

В: Удалятся ли товары, которых нет в новом прайсе?
О: Нет. Импорт только создаёт и обновляет. Удаление — только вручную
   через админку Bitrix.

В: Нужно ли каждый раз запускать что-то вручную?
О: Нет. Достаточно положить файл в inbox — cron сделает всё сам.
   Ручной запуск нужен только разработчику (при сбоях или срочной загрузке).

В: Куда смотреть, идёт ли импорт прямо сейчас?
О: Файл import/reports/progress.log — там пишется прогресс по партиям.
   (Просмотр progress.log — через разработчика или SSH.)

В: Что делать, если цена на сайте не обновилась?
О: Проверьте, что артикул в прайсе совпадает с артикулом на сайте
   (свойство CML2_ARTICLE). Проверьте отчёт: был ли товар в «updated»,
   а не в «skipped».


--------------------------------------------------------------------------------
10. ЧЕГО НЕ ДЕЛАТЬ
--------------------------------------------------------------------------------

  ✗ Не класть прайсы в public_html (папка сайта) — только в import/inbox/
  ✗ Не смешивать сырой и обработанный прайс одного поставщика в inbox
  ✗ Не оставлять старые файлы в inbox при новой загрузке
  ✗ Не редактировать файлы в processed/, reports/, quarantine/ вручную
  ✗ Не удалять папку import и скрипты на сервере
  ✗ Не создавать вручную бренд «Сантехцентр» — это поставщик, не бренд
  ✗ Не публиковать токены и пароли доступа в переписке и документах


--------------------------------------------------------------------------------
11. КОГДА ЗВОНИТЬ РАЗРАБОТЧИКУ
--------------------------------------------------------------------------------

Обратитесь к техническому специалисту, если:

  • Файл в карантине, а причина в REASON.txt непонятна
  • Отчёт imported, но на сайте товары не появились
  • Нужна срочная загрузка «прямо сейчас», не дожидаясь cron
  • Нужно подключить нового поставщика
  • Нужно изменить правила разделов (маппинг категорий)
  • Массово не подтягиваются фото или цены
