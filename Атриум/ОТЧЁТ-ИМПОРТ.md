## 1. Что сделано

### 1.1. Анализ данных поставщиков

Разобраны форматы всех трёх поставщиков из папки `API   +  (исходники таблиц ТМ)/`:

| Поставщик | Данные | Особенность |
|-----------|--------|-------------|
| ПЛИТКА «АРТКЕРА» | 6 Excel по брендам (Alma Ceramica, AltaCera, Delacora, LCM, NewTrend, Artkera Group), 42–49 колонок | Одинаковые поля, разный порядок колонок |
| ТМ RGW | 10 Excel по категориям, 17–36 колонок | Свои характеристики у каждой категории, разнобой заголовков; API нет — предлагают FTP |
| Центр Сантехники | Файл 3834 SKU × 151 колонка + аксессуары | Есть REST API остатков (ключ — по письму с ИНН) |

### 1.2. Парсинг прайса Арткеры

- Скрипт `ПЛИТКА "АРТКЕРА"/scripts/parse_and_enrich.py`: иерархический прайс (1457 позиций) → 6 файлов по брендам в `parsing/` в формате эталона «с обработкой».
- Цена: РРЦ → «Цена, руб.» (сверено с эталоном).
- Обогащение: данные из прежнего каталога + фото с сайтов поставщиков (altacera.ru, almaceramica.ru, artkera.ru).
- По code review исправлены: баг генерации фото-URL, защита от soft-404 (Content-Type), контроль дубликатов артикулов, очистка «(9 шт в уп/…)» из названий.

### 1.3. Аудит сайта

- Каталог: ИБ 61 (34 479 товаров, 225 разделов) + ИБ 64 «Торговые предложения» (SKU) + справочник брендов (ИБ 68).
- Ключ товара: свойство `CML2_ARTICLE`; типы цен: BASE (розница) и OPT (опт) — один сайт в режиме Aspro «опт+розница».
- Товары этих же поставщиков **уже есть на сайте** (прежние импорты) → подтверждена стратегия строгого upsert.
- Колонки «Путь» в файлах совпадают с деревом сайта → маппинг категорий получен реверсом.

### 1.4. ТЗ универсального импорта

Документ `IMPORT-ТЗ.md`: архитектура «канонический JSON + YAML-профили поставщиков», правила upsert, словарь атрибутов, этапы, чек-лист онбординга нового поставщика.

### 1.5. Импортёр на сайте (PHP)

| Файл | Назначение |
|------|------------|
| `public_html/local/php_interface/atrium_import/AtriumImporter.php` | Upsert по `CML2_ARTICLE`, цены BASE/OPT, бренды (поиск/создание в справочнике), разделы, остатки, фото новым товарам |
| `public_html/local/tools/import/receive.php` | Endpoint: токен `X-Import-Token`, порции ≤200, **dry-run по умолчанию** |
| `public_html/local/tools/import/config.php` | Токен, ИБ 61, типы цен |

Никаких удалений: импорт только создаёт и обновляет.

### 1.6. Конвертер и профили (Python)

- `import/convert.py` — универсальный конвертер Excel → канонический JSON по YAML-профилям (синонимы колонок, категории, дефолты).
- `import/suppliers/artkera/` — профиль + маппинг категорий (5 путей → 2 раздела сайта).
- Результат Арткеры: **1367 товаров** (90 дублей артикулов в файлах отсеяны).

### 1.7. Тестовый импорт (подтверждён пользователем)

5 товаров (2 новых + 3 существующих): **создано 2, обновлено 3, ошибок 0**.
- Новая карточка проверена на витрине: название, цена 1620 ₽, бренд, фото, раздел.
- Идемпотентность: повторный прогон — дублей нет, все «обновить».

### 1.8. Автономный серверный конвейер

На Beget (`~/atriumceramic.sheer26.ru/import/`, вне public_html):

```
inbox/{поставщик}/ → конвертация → валидация → dry-run → импорт → processed/ + отчёт
                         ↓ (ошибки/аномалии)
                     quarantine/ + причина
```

- `run_import.py` — оркестратор: карантин при ошибках, лимит автосоздания (500), lock от параллельных запусков, флаги `--dry-run-only` / `--confirm`.
- Python-зависимости поставлены (`pip3 --user`).
- **Серверный тест пройден**: 6 файлов Арткеры → dry-run: создать 203, обновить 1164, ошибок 0.
- `run_cron.sh` — обёртка для cron; `README.md` — инструкция менеджеру.

Работа менеджера сводится к: положить Excel в `inbox/{поставщик}/` → посмотреть отчёт в `reports/`.
