# atriumceramic.ru — фильтры каталога: что не так и как править

Снято 24.11.2026: наш сайт — Chrome без окна и Claude in Chrome, данные — с сервера через бридж (только чтение); santehnika-online.ru — Claude in Chrome (разделы «Душевые двери в нишу» и «Плитка»).

## Что видно на нашем сайте

### 1. Дубли значений — главная причина «фильтр не работает» и «фильтры дублируются»
По всем строковым свойствам фильтра нашлось **34 группы** одинаковых по смыслу значений; около **1700 товаров** записаны «второстепенным» вариантом. Покупатель выбирает одно значение и не видит половину товаров. Примеры:

| Свойство | Значения |
|---|---|
| Конструкция дверей | Распашная (489) / Распашные (432); Неподвижная (540) / Неподвижные (165) / Неподвижное (1); Складная / Складные; Раздвижная / Раздвижные |
| Покрытие профиля | Матовое (375) / Матовая (259); Глянцевое (1216) / Глянцевая (75) |
| Монтаж | Настенный (235) / Настенная (2); Встраиваемый (44) / Встраиваемая (9) |
| Форма | Прямоугольная (3159) / Прямоугольный (8) |
| Страна производства | «Германия» / «Германия.» и значения с невидимыми символами |
| Размеры, см | 20 групп с одинаковыми размерами, записанными по-разному (х/x, пробелы) |
| Поддон в комплекте | «Нет, приобретается отдельно» / «Приобретается отдельно» |

Источник — импорт: значения приходят от поставщиков как есть. Если чистить только на сайте, следующая выгрузка вернёт дубли.

### 2. В фильтре включены пустые и бесполезные свойства
Раздел «Душевые двери» (1393 товара), заполненность по разделу:
- «Тип товара» — 0%, «Наличие экрана» (свойство без кода) — 0% — висят в настройках во всех разделах;
- «Стиль» — одно значение «Современный» на 93% товаров; «Анти капля» — одно значение «Да» — выбирать нечего;
- «Цвет» (COLOR_REF2) — 1% заполнен, а «Цвет профиля» — 94% (это пункты ТЗ 35–36);
- «Со скидкой: Да (1)», «Наши предложения: Все / Акция» — почти пусто.

Раздел «Плитка» (11 913 товаров):
- «Коллекции» — **2308 значений** списком, вторым блоком сверху: пользоваться невозможно;
- «Размеры, см» — 209 значений, отсортированы как текст («100x100» раньше «10x10»), при этом рядом уже есть ползунки «Длина» и «Ширина»;
- «Форма», «Назначение» — 0%.

Смесители (`/catalog/santekhnika/smesitely/`; поправка 24.11: адрес `/smesiteli/` с H1 «Каталог» был моей опечаткой — это 404): в фильтре нет ничего про смесители — назначения (раковина/ванна/кухня), цвета, монтажа; есть «Наличие экрана». «В наличии» — только «Нет (421)».

### 3. Неправильные H1
- У раздела «Сантехника» (ID 255) в шаблоне H1 вписан готовый текст «Сантехника для ванной в Симферополе». Шаблон наследуется → **у всех подразделов сантехники одинаковый H1** («Душевые двери» показывают «Сантехника для ванной в Симферополе»). Плитка (ID 256) — то же, свой текст.

### 4. Мелочи интерфейса
- В сортировке есть пункт без названия: «(убывание)» / «(возрастание)».
- Мобильный: до кнопки «Открыть фильтры» почти целый экран (H1 на 4 строки, плитки подразделов, «Товары/Коллекции», сортировка) — товаров на первом экране нет. Фильтр открывается, но **после выбора значения ничего не происходит на экране**: кнопка «Показать 7827 товаров» — в самом низу длинного списка (~3 экрана ниже), всплывашка «Выбрано 7827» — за краем экрана, а закреплённая внизу кнопка — «Закрыть фильтр». Вот это и есть «на моб версии полетели фильтры».
- **Адреса фильтра индексируются**: любая комбинация `/filter/…/apply/` отдаёт `index, follow`, canonical на саму себя и общий H1 раздела → тысячи страниц-дублей для поисковиков.
- «В наличии: Да (14) / Нет (1379)» в душевых дверях — либо остатки не загружаются, либо значение «Нет» нужно прятать.

### 5. Что в порядке
Фасетный индекс включён; ползунки цены и размеров работают; есть «Показать ещё» и номера страниц; адреса фильтра человекочитаемые (`/filter/…/apply/`).

## Как править (по убыванию отдачи)

1. **Словарь значений в импорте.** В `AttributeMapper.php` / `attributes.yaml` — таблица «как пришло → как пишем» для 34 групп; один раз прогнать по базе с пробным прогоном и отчётом, затем пересобрать фасетный индекс. Без этого шага всё остальное откатится со следующей выгрузкой.
2. **Настройка фильтра по разделам** (галочка «в умном фильтре» у раздела): убрать пустые и одно-значные свойства; в дверях оставить «Цвет профиля», убрать «Цвет»; «Коллекции» в плитке — убрать из фильтра или опустить вниз с поиском по значениям; «Размеры» в плитке — только популярные размеры, отсортированные по числу, или оставить ползунки. Порядок блоков — по ТЗ.
3. **H1.** Шаблон заголовка у подразделов сантехники и плитки — `{=this.Name} в Симферополе` (сам «Сантехника» оставить своим текстом); SEO-страницам фильтра задать свои H1.
4. **Сортировка** — дать имя пустому пункту или убрать.
5. **Мобильный** — кнопка «Фильтры» рядом с сортировкой сразу под H1 (липкая при прокрутке), проверить открытие.
6. **Удобство (по образцу крупных магазинов, сверить с santehnika-online):** выбранные значения «чипсами» над товарами с крестиком и «Сбросить всё», поиск внутри длинных списков (бренды), быстрые теги популярных фильтров над товарами, счётчики у значений (уже есть).

После каждого шага — `python3 tools/after_edit.py` (сброс кеша, проверка страниц).

## План правок с учётом сравнения

**Этап 1 — данные и настройка (без вёрстки, 2–3 дня):**
1. Словарь значений в импорте + чистка 34 групп дублей, пересборка фасетного индекса.
2. По каждому разделу: убрать пустые/одно-значные блоки, «Цвет» → «Цвет профиля» в дверях, «Коллекции» из списка убрать (оставить поиск — п. 6), порядок по ТЗ; «В наличии» показывать только «Да».
3. H1 разделов из названия; комбинациям фильтра — `noindex` и canonical на раздел (сейчас индексируются).

**Этап 2 — мобильный (1 день):**
4. Закреплённая внизу кнопка «Показать N товаров» вместо «Закрыть фильтр»; кнопка «Фильтры» сразу под H1.

**Этап 3 — удобство как у santehnika-online (3–5 дней, шаблон фильтра Аспро):**
5. Применение сразу при клике (режим AJAX у умного фильтра) + плашки выбранных значений с ✕ над товарами.
6. Поиск по значениям в длинных списках (бренды, коллекции); бренды по количеству товаров, 10 сразу + «Посмотреть все».
7. Размеры плитки: 5–8 популярных кнопками над товарами и в фильтре, остальное — «Посмотреть все».
8. «Популярные подборки» над товарами — ссылки на SEO-страницы фильтра (у нас модуль dwstroy.seochpulite / умное SEO Аспро) со своим H1 и текстом, `index`.
9. В карточке списка — 1–2 ключевых свойства (двери: ШхВ; плитка: толщина, цена за м²).

Этапы 1–2 дают основной эффект: «фильтр не работает», «дублируется», «на мобильном полетели» закрываются ими.
