Отправляет заявки Contact Form 7 и заказы WooCommerce в группу Telegram.

== Description ==

Плагин ставится через админку WordPress. В настройках указывается токен бота, выбирается группа, в которой бот уже состоит, и нажимается тестовая отправка.

К каждой заявке и заказу добавляется источник: поиск (SEO), реклама, соцсеть, переход по ссылке или прямой заход, плюс страница входа и первый заход, если он был раньше.

В группу уходят только отмеченные формы Contact Form 7. Заказы WooCommerce отправляются отдельно, по одному разу.

== Installation ==

1. Загрузите архив плагина через «Плагины → Добавить новый → Загрузить плагин».
2. Включите плагин.
3. Откройте «Telegram заявки», вставьте токен бота и сохраните.
4. Добавьте бота в группу и отправьте туда /start.
5. Нажмите «Обновить список групп», выберите группу и сохраните.
6. Нажмите «Отправить тест».
7. Отметьте нужные формы Contact Form 7 и заказы WooCommerce.
