# Референсы вёрстки — сводка для @коля

Изучены проекты в `reference/`. При новой задаче открывать **ближайший по типу** и копировать паттерны.

**Чек-лист перед сдачей:** [`чек-лист_верстальщика.md`](чек-лист_верстальщика.md) · [Google Docs](https://docs.google.com/document/d/11ba7tZWpTh9AT6W7o4LAbFqt0kmSfdk2HSMrtRK6Vjg/edit)

## Общее для всех проектов

### HTML `<head>`
- `lang="ru"`, IE conditional comments (legacy)
- Meta: `charset`, `X-UA-Compatible`, `viewport` с `maximum-scale=1`, `format-detection: telephone=no`
- CSS libs → `fonts.css` → `main.css?ver=` → `media.css?ver=`

### Структура CSS
| Файл | Содержимое |
|------|------------|
| `fonts.css` | `@font-face`, local() + woff2/woff/ttf |
| `main.css` | Reset, компоненты, **без** @media |
| `media.css` | Только media queries |

### JS
- jQuery 3.6 первым
- Плагины: fancybox, slick, datetimepicker, mask — по необходимости
- `common.js?ver=` последним
- **Якоря:** плавный скролл jQuery `.animate({ scrollTop }, 500)` (или 600 ms по ТЗ), offset шапки; исключить `.fancybox` и `.tabs-page a`. Базовый паттерн — `getAnchorOffset()` + `.header` (`туроператор/js/common.js`). **Berega object:** `.zk-anchors__inner a[href^="#"]`, offset = `.hero-header` + `.zk-anchors` + 16px — см. `примеры/2026-05-21_Berega_zk-anchors_плавный_скролл.md`

### Font Awesome (libs)

В проектах Sheer в `libs/fontawesome-free-5.12.0-web/css/all.min.css` часто подключён **Font Awesome 5 Pro** (не Free).

| Где | Правило |
|-----|---------|
| Классы `.fas`, `.fa-check` в HTML | Работают через `all.min.css` |
| Псевдоэлементы `.checkbox label span::after` | `font-family: 'Font Awesome 5 Pro'`, `font-weight: 400`, `\f00c`, паттерн opacity — см. **`примеры/2026-05-20_чекбокс_fontawesome_pro.md`** |
| **Запрещено** | `'Font Awesome 5 Free'` + `900`, если в libs **Pro** — галочка не отобразится |

Перед формой: открыть заголовок `all.min.css` и сверить Pro/Free.

### Bootstrap
- `libs/bootstrap/bootstrap-grid.css` (не полный bootstrap.min, а grid)
- `.container` или `.container-fluid` + `.row` + `.col-*`
- **Запрещено:** `gap` на `.row`

### Именование
- BEM-подобное: `.header__wrapper`, `.btn-main`, `.item-form`
- Модификаторы: `.btn-main--light`, `.header.default` / `.header.fixed`

### Общие классы (DRY) — обязательно

**Одинаковый вид = один класс.** Не плодить `.about__btn`, `.team__btn`, если везде подходит `.btn-main`.

| Тип | Общие классы |
|-----|----------------|
| Кнопки | `.btn-main`, `.btn-main--light`, `.btn-main--dark`, `.btn-main_border` |
| Ссылки | `.link-page`, `.phone-main` |
| Заголовки | `.title-section`, `.title-small`, `.title-min` |
| Текст | `.descr-section` |
| Формы | `.item-form`, `.input-phone`, `.checkbox` |
| Карточки / списки | `.item-advantage`, `.item-team`, `.item-question`, `.item-dropdown`, `.item-contact`, `.item-product`, `.item-news` |
| Шапка секции | `.head-section` |
| Модалки | `.modal-block`, `.modal-wrap`, `.descr-modal` |

Секция (`.team`, `.services`) задаёт только отступы и фон; кнопки и карточки — те же классы, что на всём сайте.

## zarina 3 — ГЛАВНЫЙ ЭТАЛОН

**Путь:** `reference/zarina 3/`  
**Тип:** отель / гостиница  
**Страницы:** index, catalog, card, about, news, article, contacts, infrastructure, map

### Libs (полный набор)
- bootstrap-grid, fontawesome, fancybox, datetimepicker, slick

### Брейкпоинты (`media.css`)
```
1800px → 1730px → 1400px → 1200px → 992px (mobile)
+ min-width 992/1400/1730, (hover: hover/none)
```

### Header
- `.header.default` / `.header.fixed` — scroll в common.js
- `.sandwich` (3 div), `.menu-mobile`, `.menu-overlay`, `body.body--menu`
- `.phone-mobile`, `.socials-list`, `.header__contacts`

### Секции
- `.billbord` + `.form-booking` (absolute, backdrop-filter blur)
- `.consultation` — grid форма (gap разрешён — не `.row`)
- Slick-слайдеры с FA-стрелками
- Footer-аккордеон на `< 992px`

### common.js — обязательные блоки
- Header scroll fixed/default
- Sandwich menu
- datetimepicker ru + minDate связка
- `.input-phone` mask
- slick init + responsive 992
- fancybox `autoFocus: false, backFocus: false`
- scroll-up / scroll-down
- footer accordion `width < 992`

## UltraDent

**Путь:** `reference/UltraDent/`  
**Тип:** стоматология

### Отличия от zarina

- Before/after слайдер
- Дополнительные мобильные breakpoints

## WithLove (5) — каталог, мобильный фильтр

**Путь:** `reference/WithLove (5)/`  
**Тип:** интернет-магазин / каталог

### Паттерн `.btn-main_filter`

| Элемент | Реализация |
|---------|------------|
| Кнопка | `.btn-main.btn-main_border.btn-main_filter` перед сайдбаром |
| Сайдбар | `.sidebar-catalog` — на &lt;992px `display: none`, открывается по клику |
| JS | `slideToggle(200)` + `toggleClass('active')` |
| Desktop ≥992px | кнопка `display: none !important`, сайдбар `display: block !important` |

**Agro-As-адаптация:** `.catalog-sidebar`, `.btn-main--outline`, цвет outline `#052d24` — см. **`примеры/2026-05-20_Agro-As_btn-main_filter_мобилка.md`**.

## Модалка «Заказать звонок» (обязательный паттерн Коли)

При любой вёрстке, где есть CTA обратного звонка:

| Элемент | Реализация |
|---------|------------|
| Триггер | `href="#modal-callback"` + `class="fancybox"` |
| Контент | `#modal-callback` → `.modal-wrap` + форма |
| Поля | имя, `input-phone` (+ маска), чекбокс, submit |
| JS | Fancybox `autoFocus: false`, `backFocus: false`, маска в `afterShow` |
| CSS | `.modal-block`, `.modal-wrap`, `.descr-modal` — px, адаптив в `media.css` |

**Не делать:** `href="#consultation"` или скролл к форме вместо модалки.
