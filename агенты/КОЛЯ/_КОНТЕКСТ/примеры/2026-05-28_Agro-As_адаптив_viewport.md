**Проект:** `Agro-As/maintheme`  
**Файлы:** `css/media.css`, `css/main.css` (база hero), `js/common.js`, `header.php` / `footer.php` (`?ver=`)  
**Статус:** обязательный канон для `@коля` при любых правках адаптива Agro-As.

**Связано:** `2026-05-19_Agro-As_главная_паттерны.md` (§7 wholesale), `2026-05-27_Agro-As_products_slider.md`, лог `_ЛОГИ/2026-05-28_Agro-As_адаптив_1024x640.md`.

## 1. Целевые разрешения (проверять в браузере)

| Viewport | Роль | Что проверять |
|----------|------|----------------|
| **1920×1080** | Desktop полный | Wholesale 653px, products 4 col, billbord `main.css` |
| **1400–1599** | Компактный desktop | Wholesale 4 в ряд (не 2×2!), типографика §5 |
| **993–1024** | MacBook scaled / компактный desktop | Burger header, каталог 2 col, billbord + wholesale в экран |
| **1024×640** | Низкая высота (Air) | Hero **без скролла** (или минимум пустоты), sticky off |
| **≤992** | Мобилка | Стек wholesale, фильтр каталога, sandwich |
| **≤575** | Узкая мобилка | Products 1 col |

**Критерий hero (`.billbord`):** идеал — **один экран без скролла**; допустимо — компактно, без «пустой» высоты. Не обрезать контент под header.

## 2. Правила `media.css` (структура)

1. **Один `@media` на диапазон** — не плодить дубли (слияние ver 7.5).
2. **Порядок:** products slider (flex) → `max-width` 1800→575 → `min-width` overrides в **конце** (каталог sticky **1025px**).
3. **Все `@media` только в `media.css`**, не в `main.css`.
4. После правок — **увеличить `?ver=`** в `header.php` (`media.css`) и `footer.php` (`common.js` при JS).
5. Таблица брейкпоинтов — в **шапке** `Agro-As/maintheme/css/media.css`.

## 3. `.billbord` + fixed header (КРИТИЧНО)

На главной `.header` — **`position: fixed`**. Контент hero **не должен заходить под шапку**.

### Ошибка (не повторять)

- Обнулять **только** `.billbord__spacer` и компенсировать уменьшенным `padding-top` — контент уезжает **под header**.
- Дублировать отступ: большой `padding-top` **и** большой spacer.

### Правильно

| Свойство | Назначение |
|----------|------------|
| `.billbord__spacer` | **Зазор под fixed header** (основной механизм на адаптиве) |
| `.billbord { padding-top }` | На адаптиве **`0`** (на desktop в `main.css` остаётся `25px` + spacer `134px`) |
| Компактность hero | Уменьшать **margin** у title/list/features/promo, `padding-bottom`, при `max-height: 640px` — типографику |

### Высота spacer (актуально `media.css` ver **7.7**)

| Условие | `.billbord__spacer` | `.billbord` padding-top |
|---------|---------------------|-------------------------|
| `main.css` (≥1601, полный desktop) | **134px** | **25px** |
| `max-width: 1400px` | **118px** | **0** |
| `max-width: 1200px` | **110px** | **0** |
| `993–1024px` | **80px** | **0** |
| `max-height: 640px` (все ширины) | **88px** | **0** |
| `max-height: 640px` + `min-width: 1025px` | **106px** | **0** |
| `993–1024` + `max-height: 640px` | **84px** | **0** |
| `max-width: 992px` | **88px** | **0** |
| `max-width: 992px` + `max-height: 640px` | **72px** | **0** |

**Ориентир высоты header (для подстройки spacer ±4px):**

- Full nav: `padding 25×2` + logo **72px** ≈ **122px**
- ≤1200: logo **65px** + padding ≈ **115px**
- 993–1024 burger: `padding 14×2` + logo **56px** ≈ **84px**
- ≤992 mobile: `padding 16×2` + logo **59px** ≈ **91px**

При `max-height: 640px` допустимо `max-height: 100dvh` + `overflow: hidden` на `.billbord` — только если контент всё равно не влезает после spacer/margin.

## 6. Слайдер `.products__slider`

**CSS** (`media.css`, flex без Slick):

| Ширина | Колонок |
|--------|---------|
| ≥1201 | 4 (25%) |
| 949–1200 | 3 (33.33%) |
| 576–948 | 2 (50%) |

**JS** (`common.js`, `getProductsSliderSlidesToShow` + Slick `responsive`):

- `≤575` → 1, `≤948` → 2, `≤1200` → 3, иначе 4
- Slick breakpoints: **1201**, **949**, **576**
- Закрытие меню по клику на ссылку: **`width < 1025`**

## 8. Алгоритм для @коля (автокоррекция)

При задаче «адаптив / 1024 / hero / wholesale / media.css»:

1. **Открыть этот файл** и `2026-05-19_Agro-As_главная_паттерны.md`.
2. Править **только** `media.css` (+ `common.js` если слайдер/меню).
3. Hero: **сначала** проверить `.billbord__spacer` ≥ высоты header на целевом breakpoint; **не** обнулять spacer без пересчёта.
4. Компактность: уменьшать **margin/padding-bottom/шрифты**, не снимать spacer.
5. Wholesale 1400–1599: режим **4 в ряд**, не восстанавливать удалённый 2×2.
6. Каталог sticky / sidebar: порог **1025px**, не 992.
7. Обновить `?ver=` в `header.php` / `footer.php`.
8. Прогнать чеклист §9.

## Частые ошибки

| Ошибка | Правильно |
|--------|-----------|
| `spacer: 0` + маленький `padding-top` на billbord | Spacer ≈ высота header, `padding-top: 0` на адаптиве |
| Каталог sticky с **992px** | Sticky / sidebar с **1025px** |
| Wholesale 2×2 на 1400–1599 | 4 в ряд 993–1599, полный макет ≥1600 |
| Дубли `@media` для одного диапазона | Один блок на диапазон |
| Сжимать hero только `min-height: 960px` | `min-height: 0` + spacer + компактные margin |
