# 2026-05-19 — Общие классы для повторяющихся элементов

## Правило

При вёрстке всё, что **выглядит одинаково**, получает **один общий класс**. Отличия — только модификатором. Секция не дублирует стили кнопок и карточек.

## Плохо

```html
<a href="#" class="about-btn">Связаться</a>
<a href="#" class="team-btn">Связаться</a>
```

```css
.about-btn { height: 50px; background: #1a5f8a; … }
.team-btn { height: 50px; background: #1a5f8a; … }
```

## Хорошо

```html
<a href="#contacts" class="btn-main btn-main--dark">Связаться с нами</a>
<a href="#modal-callback" class="btn-main fancybox">Связаться</a>
```

```css
.btn-main { … }
.btn-main--dark { background: #1a5f8a; }
```

## Эталон в проекте

`туроператор/` — `.btn-main`, `.link-page`, `.title-section`, `.item-team`, `.item-question`, `.head-section`.

## Результат

Оценка: ✅ Отлично

## Урок

Пользователь: при правках проще менять один класс, чем искать дубли по секциям. Правило вошло в обязательный чеклист @коля.
