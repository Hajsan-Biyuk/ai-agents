# 2026-05-19 — Плавный скролл к якорям

## Правило

Навигация `href="#section"` — через jQuery `.animate()`, не нативный jump.

## Скрипт (эталон)

```js
function getAnchorOffset() {
  var gap = 16;
  var $header = $(".header");
  if ($header.hasClass("fixed")) {
    return $header.outerHeight() + gap;
  }
  return $header.find(".header__wrapper").outerHeight() + 30 + gap;
}

$("a[href^='#']").on("click", function (e) {
  // …
  scrollTop: targetElement.offset().top - getAnchorOffset()
});
```

## Исключения

- `.fancybox` — модалки
- `.tabs-page a` — табы
- `href="#"` — заглушки
