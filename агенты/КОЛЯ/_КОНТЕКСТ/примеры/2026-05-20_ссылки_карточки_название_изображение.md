# Ссылки на карточках: название + изображение (2026-05-20)

**Статус:** ✅ обязательное правило @коля  
**Эталоны:** `reference/zarina 3/article.html` (`.item-news`), `Agro-As/` (`.item-product`)

---

## Правило

В карточках **товара**, **похожих товаров**, **новостей**, **статей** и любых превью с переходом на детальную страницу — **две отдельные ссылки** на один URL:

1. **Изображение** — обёртка-ссылка вокруг `<img>`
2. **Название** — `<a>` с классом заголовка карточки

Кнопки действия («Заказать», «Читать», «В корзину») — **отдельно**, не внутри общей ссылки на карточку.

---

## Зачем

- UX: клик по фото и по названию ведёт на карточку/статью (ожидание пользователя)
- SEO и доступность: осмысленные `href`, `alt` у картинки
- Не ломать CTA: кнопка заказа остаётся `<button>` / отдельная ссылка

---

## HTML — товар (Agro-As `.item-product`)

```html
<div class="item-product">
  <div class="item-product__top">
    <a href="card.html" class="item-product__image">
      <img src="img/product-1.png" alt="NPK комплекс">
    </a>
    <span class="item-product__tag">Удобрения</span>
  </div>
  <div class="item-product__body">
    <a href="card.html" class="item-product__name">NPK комплекс</a>
    <!-- meta, price -->
    <button type="button" class="btn-order">Заказать</button>
  </div>
</div>
```

| Элемент | Ссылка |
|---------|--------|
| `.item-product__image` → `img` | ✅ `href` на карточку |
| `.item-product__name` | ✅ тот же `href` |
| `.item-product__tag` | ❌ не ссылка (бейдж категории) |
| `.btn-order` | ❌ кнопка заказа, не оборачивать карточку |

**Где применять в Agro-As:** `index.html` (слайдер товаров), `category.html` (сетка), `card.html` (блок «Рекомендуем»).

## HTML — новости / статьи (эталон zarina `.item-news`)

```html
<div class="item-news">
  <a href="article.html" class="item-news__image">
    <img src="..." alt="">
  </a>
  <div class="item-news__content">
    <a href="article.html" class="item-news__title">Заголовок статьи</a>
    <div class="item-news__text">...</div>
    <div class="item-news__bottom">
      <a href="article.html" class="link-page">Читать</a>
    </div>
  </div>
</div>
```

Тот же принцип: **картинка** и **заголовок** — ссылки; анонс и отдельная кнопка «Читать» — по макету.

---

## Запрещено

```html
<!-- ❌ Одна ссылка на всю карточку — кнопка «Заказать» внутри <a> недопустима -->
<a href="card.html" class="item-product">
  <img ...>
  <span class="item-product__name">...</span>
  <button class="btn-order">Заказать</button>
</a>

<!-- ❌ Только название без ссылки на фото -->
<div class="item-product__top">
  <img src="..." alt="">
</div>
<a class="item-product__name">...</a>
```

## CSS (обязательно при hover scale на фото)

Если на hover картинка увеличивается (`transform: scale`):

```css
.item-product__image {
  display: flex;
  flex: 1 1 auto;
  overflow: hidden; /* zoom не наезжает на тег */
}

.item-product__tag {
  position: relative;
  z-index: 2;
}

a.item-product__name {
  display: block;
  color: #052d24;
  text-decoration: none;
}

a.item-product__name:hover {
  text-decoration: underline;
}
```

Для `.item-news__image` — аналогично `overflow: hidden` при zoom в макете.

Стили ссылок — **общие** в `main.css`, не дублировать под каждую страницу (`.catalog-page .item-product__name` и т.п. — только если реально другой вид).
