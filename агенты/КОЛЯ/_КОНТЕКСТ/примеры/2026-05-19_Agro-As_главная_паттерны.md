## 1. Контейнер `container-main`

**Ошибка (не делать):** `max-width: 1600px` + `padding: 160px` → контент ~1280px.

**Правильно (Figma: холст 1920px, поля 160px, контент 1600px):**

```css
.container-fluid.container-main,
.container-main {
	width: 100%;
	max-width: 1920px;
	margin-left: auto;
	margin-right: auto;
	padding-left: 160px;
	padding-right: 160px;
	box-sizing: border-box;
}
```

**Адаптив** (`media.css`):

| Breakpoint | padding-left/right |
|------------|-------------------|
| ≤1800px    | 100px             |
| ≤1400px    | 40px              |
| ≤992px     | 20px              |

## 2. Bootstrap — обязательно

- Все секции: `container-fluid container-main` → `row` → `col-*`.
- **Запрещено:** `gap` на `.row`.
- Отступы между колонками — **стандартный gutter Bootstrap** (без `margin-left: -Npx` + `padding` на col), **если в ТЗ не указано иное**.

### Лишние gutter и calc на col-* — не делать без ТЗ

**Ошибка (2026-05-20):** на `categories__row` добавлены кастомные `padding 11.5px` и `calc` ширины для `col-lg-4` / `col-lg-6` — при стандартных `col-lg-*` в HTML это избыточно.

**Правильно для categories:** только `col-lg-4`, `col-lg-6` в разметке + `margin-bottom` у колонок при необходимости.

**Исключение — advantages (§4):** нестандартная пропорция 330×3 + 555 — кастомная сетка **осознанно**, зафиксирована в паттернах.

Подробнее: `примеры/2026-05-20_bootstrap_без_лишних_col.md`

## 5. Карточка товара `.item-product` (КРИТИЧНО)

### Размеры и тень (Figma)

- Карточка: max-width **382px**, `border-radius: 20px`, тень `0 4px 15px rgba(0,0,0,0.08)`.

### Верхняя зона `.item-product__top`

- Высота: **296px** (не 280px).
- Фон: `#f5f5f5`, скругление сверху `20px 20px 0 0`.
- Layout: **flex column**, `padding: 7px 10px 10px`.

### Изображение

- **НЕ** `object-fit: cover` — товар обрезается.
- **ДА:** `object-fit: contain`, центрирование.
- Лимиты: `max-width: min(243px, 100%)`, `max-height: 282px`.
- `flex: 1 1 auto`, `margin: 0 auto` — картинка целиком в серой зоне.

### Тег `.item-product__tag`

- **НЕ** `position: absolute; top: 16px` — тег был сверху, это ошибка.
- **ДА:** внизу серой зоны:
  - `margin-top: auto` (прижать к низу flex-колонки),
  - `margin-bottom: 19px` (+ `padding-bottom: 10px` у `__top` = **29px** от низа блока по Figma, тег на y:237),
  - `align-self: flex-start`, `left` визуально через padding родителя `10px`.
- Стили: `padding: 6px 8px`, `background: #f6fedd`, `font-weight: 400`, `font-size: 14px`, `line-height: 130%`.

### Низ `.item-product__body`

- `margin-top: -20px` — нахлёст на серую зону (белый блок с y:276 в макете).
- `padding: 20px`, `gap: 28px`, `border-radius: 20px`, `z-index: 2`, фон `#fff`.
- Заголовок `.item-product__name`: **20px** (не 24px).

### HTML (порядок в `__top`)

```html
<div class="item-product__top">
	<img src="img/product-1.png" alt="...">
	<span class="item-product__tag">Удобрения</span>
</div>
```

## Частые ошибки (не повторять)

| Ошибка | Правильно |
|--------|-----------|
| `object-fit: cover` на фото товара | `contain` + max 243×282 |
| Тег сверху (`top: 16px`) | Тег снизу: `margin-top: auto` + `margin-bottom: 19px` |
| `max-width: 1600px` у контейнера | `1920px` + padding 160px |
| Flex-сетка вместо `row`/`col-*` | Bootstrap Grid |
| `gap` на `.row` | Только gutter Bootstrap |
| FA Free в `.checkbox::after` при Pro в libs | `'Font Awesome 5 Pro'`, weight 400 — см. `2026-05-20_чекбокс_fontawesome_pro.md` |
| Заголовок карточки 24px | 20px по макету |
| `margin-left: -233px` на всей `.wholesale__panel` | Только на `.wholesale__types` |
| `padding-left: 310px` у wholesale | `20px` у head / benefits / actions; у types — нет |
| `spacer: 0` на billbord + малый padding-top | Spacer ≈ высота header — см. `2026-05-28_Agro-As_адаптив_viewport.md` |
| Wholesale 2×2 на 1400–1599 | 4 в ряд 993–1599 |
