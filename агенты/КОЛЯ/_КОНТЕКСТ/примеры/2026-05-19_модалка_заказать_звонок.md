# 2026-05-19 — Модалка «Заказать звонок»

## Задача

При клике на «Заказать звонок» в шапке открывать форму в модалке (Fancybox), как в `reference/Артэк/index.html`.

## Решение

**Проект:** `туроператор/`

### HTML — триггер

```html
<a href="#modal-callback" class="link-page fancybox">Заказать звонок</a>
```

Дублировать в `.header__contacts` и `.menu-mobile`.

### HTML — модалка (перед `<script>`)

```html
<div id="modal-callback" class="modal-block">
  <div class="modal-wrap">
    <div class="title-section">Закажите звонок</div>
    <div class="descr-modal">и наш менеджер свяжется с вами в течение 15 минут</div>
    <form>
      <div class="item-form"><input type="text" placeholder="Ваше имя" required></div>
      <div class="item-form">
        <input type="tel" class="input-phone" inputmode="numeric" placeholder="Номер телефона" required>
      </div>
      <input type="submit" class="btn-main" value="Отправить">
      <div class="checkbox">...</div>
    </form>
  </div>
</div>
```

### JS (`common.js`)

```js
$(".fancybox").fancybox({
  autoFocus: false,
  backFocus: false,
  afterShow: function (instance, current) {
    if (current && current.$content) {
      current.$content.find(".input-phone").mask("+7 (999) 999-99-99");
    }
  }
});
```

### CSS

- `.modal-block { display: none; }`
- `.modal-wrap` — padding, border-radius, фон бренда
- `.fancybox-slide--html .fancybox-close-small` — цвет крестика
