# Bootstrap — без лишних gutter и calc на col-* (2026-05-20)

**Причина:** в Agro-As на секции categories добавлены кастомные отступы и переопределение ширины колонок без необходимости. Пользователь попросил убрать; для advantages кастомная сетка оставлена — там пропорции не совпадают со стандартным Bootstrap.

---

## Правило @коля

**Без явной задачи в ТЗ / нестандартного макета — не добавлять:**

1. **Кастомный gutter на row/col:**
   ```css
   /* ❌ */
   .section__row { margin-left: -11.5px; margin-right: -11.5px; }
   .section__row > [class*="col-"] {
     padding-left: 11.5px;
     padding-right: 11.5px;
   }
   ```

2. **Переопределение ширины Bootstrap-колонок:**
   ```css
   /* ❌ */
   .section__row > .col-lg-4 {
     flex: 0 0 calc((100% - 46px) / 3);
     max-width: calc((100% - 46px) / 3);
   }
   ```

**По умолчанию:** подобрать нужные `col-lg-*` / `col-md-*` в HTML и положиться на gutter Bootstrap.

---

## Когда кастомная сетка допустима

Только если **в Figma пропорции не кратны** стандартным колонкам Bootstrap.

**Пример Agro-As — advantages (оставить):**
- 3×330px + 1×555px в ряд на 1545px контента
- `.advantages__row` + `calc` в `media.css` ≥1200px
- См. `2026-05-19_Agro-As_главная_паттерны.md` §4

**Пример Agro-As — categories (убрать calc):**
- Стандартные `col-lg-4` (3 в ряд) и `col-lg-6` (2 в ряд)
- Достаточно классов Bootstrap, без доп. CSS на ширину
