# Agro-As — подключение шрифтов (2026-05-20)

**Проблема:** все URL Manrope v15 и Ubuntu v20 в `@font-face` отдавали **404** → Arial fallback, synthetic bold.

**Решение:**

```
Agro-As/fonts/
  manrope-cyrillic-ext.woff2
  manrope-cyrillic.woff2
  manrope-latin.woff2
  ubuntu-cyrillic.woff2
  ubuntu-latin.woff2
```

`css/fonts.css`:
- Manrope — variable font, `font-weight: 400 800`, `unicode-range` для cyrillic + latin
- Ubuntu — `font-weight: 700`, cyrillic + latin
- Пути: `url('../fonts/…')`

**Self-check перед сдачей:**
```bash
curl -sI "https://…"  # если CDN — обязательно 200
ls Agro-As/fonts/*.woff2
```

**Figma weights (главная):**
- `.title-section` — 600
- `.descr-section` — 500
- `.billbord__title strong` — 800 + uppercase
- `.menu-pills`, `.btn-catalog`, `.btn-order` — 600 / lh **140%**
- `.phone-main` — 700
