# Формы — корректная разметка

**Обязательно для @коля** при любой форме на сайте (модалки, секции, страницы).

**Главный эталон:** `reference/Артэк/index.html`  
**Реализация Agro-As:** `Agro-As/contacts.html`, `Agro-As/wholesale.html`, `Agro-As/maintheme/footer.php`  
**Пример кейса:** `примеры/2026-05-25_Agro-As_формы_item-form.md`

---

## Принцип

Внутри `<form>` — **минимум классов**. Только:

| Что | Классы |
|-----|--------|
| Сетка | Bootstrap: `row`, `col-*`, `align-items-*` — **когда нужна раскладка** |
| Поле | `.item-form` (+ редкий модификатор, напр. `.item-form--message`) |
| Телефон | `.input-phone` на `<input type="tel">` |
| Согласие | `.checkbox` — **`label` → `input` + `span`** (CSS: `.checkbox label span`) |
| Отправка | `.btn-main` (+ модификатор кнопки, напр. `.btn-main--yellow`) |

**BEM-секции** (`.contacts-page__card`, `.wholesale-page-request__form`) — **снаружи** `<form>`, для фона/отступов блока. **Не** вешать на сам `<form>` и **не** плодить внутренние классы вида `__field`, `__form-footer`, `__checkbox`, `__submit`.

## Эталон — модалка (Артэк)

```html
<form>
  <div class="item-form">
    <input type="text" placeholder="Ваше имя" required>
  </div>
  <div class="item-form">
    <input type="tel" placeholder="Номер телефона" class="input-phone" inputmode="numeric" required>
  </div>
  <input type="submit" class="btn-main" value="Отправить">
  <div class="checkbox">
    <label>
      <input type="checkbox" required checked>
      <span>Я согласен с условиями обработки персональных данных</span>
    </label>
  </div>
</form>
```

Файл: `reference/Артэк/index.html` — `#modal-callback`, `#modal-application`, блок `.consultation form`.

## CSS

Стили полей — **не** на классах внутри `<form>`, а на:

1. **Родительском блоке секции** + `.item-form`  
   Пример: `.contacts-page__card--form .item-form { … }`
2. **Общих классах** — `.checkbox`, `.btn-main`, `.input-phone`
3. **Редкий модификатор** `.item-form--message` — только если полю нужна особая высота

```css
/* ✅ */
.contacts-page__card--form .item-form input { … }
.wholesale-page-request__form .item-form label { … }

/* ❌ */
.contacts-page__field input { … }
.wholesale-page-request__label { … }
.wholesale-page-request__submit { … }
```

Футер формы (чекбокс + кнопка в одну линию) — через `row` / `col-lg` / `col-lg-auto`, стили на `.wholesale-page-request__form form > .row:last-child .btn-main`.

## Запрещено внутри `<form>`

- ❌ Класс на `<form>` (`contacts-page__form`, `section-form` и т.п.)
- ❌ Обёртки с BEM только для формы: `__form-fields`, `__fields-row`, `__form-footer`, `__field`, `__checkbox`, `__submit`, `__label`
- ❌ `gap` на `.row`
- ❌ `id` на `<form>` (id — на внешней обёртке или модалке `#modal-callback`)

---

## Допустимо снаружи `<form>`

- Заголовок блока: `.wholesale-page-request__form-title`, `.contacts-page__label`
- Карточка/панель: `.contacts-page__card--form`, `.wholesale-page-request__form`
- Модалка: `#modal-callback.modal-block` → `.modal-wrap` → `<form>`

## Чек-лист перед сдачей

- [ ] `<form>` без своих классов
- [ ] Каждое поле в `.item-form`
- [ ] Сетка — только `row` / `col-*` (без `gap` на row)
- [ ] Телефон: `type="tel"`, `inputmode="numeric"`, `.input-phone`
- [ ] Submit: `.btn-main` или `<input type="submit" class="btn-main">`
- [ ] Согласие: `.checkbox` → `label` → `input` + `span`; CSS на `.checkbox label span` (см. `примеры/2026-05-20_чекбокс_fontawesome_pro.md`)
- [ ] Стили полей через родитель секции + `.item-form`, не через `__field`
- [ ] Модалки «Заказать звонок» — `#modal-callback` + Fancybox (см. `примеры/2026-05-19_модалка_заказать_звонок.md`)
