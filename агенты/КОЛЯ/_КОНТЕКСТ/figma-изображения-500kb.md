# Figma → img/: экспорт и лимит растровых изображений

**Обязательно для @коля** при экспорте и сохранении графики из макета Figma в проект (`img/` и аналоги).

---

## 1. Размер экспорта (до сжатия)

**Не скачивать из Figma завышенные растровые изображения** (4096 px «на всякий случай» — запрещено).

| Правило | Значение |
|---------|----------|
| Максимум экспорта | **не больше 2×** от размера картинки **на сайте** |
| Retina | 2× как раз покрывает retina — **@2x от вёрстки**, не @4x и не «полный фрейм Figma» |

### Откуда брать «размер на сайте»

1. **CSS вёрстки** — `width`, `max-width`, `height`, фактический размер блока в px.
2. **Макет Figma** — ширина/высота **конкретного слоя/фрейма**, который вставляется на страницу (не родительский artboard 1920+).
3. Если на сайте картинка **responsive** — ориентир: **максимальная ширина на desktop** из CSS/сетки.

### Примеры

| На сайте (CSS/макет) | Макс. экспорт из Figma |
|----------------------|-------------------------|
| 600×400 px | 1200×800 px |
| 1240×620 px (hero) | 2480×1240 px |
| 243×282 px (карточка товара) | 486×564 px |
| `max-width: 1600px` | ширина файла ≤ **3200 px** |

### Запрещено

- ❌ Экспорт @4x без явного ТЗ
- ❌ Скачивать artboard / секцию целиком, если на сайте используется только часть
- ❌ «Взять как в Figma 4096 px» без сверки с CSS

---

## 2. Лимит веса файла (после экспорта)

| Формат | Лимит |
|--------|-------|
| **PNG** | ≤ **500 КБ** на файл |
| **JPG / JPEG** | ≤ **500 КБ** на файл |
| SVG, WebP, GIF, PDF, шрифты | **не входят** в это правило |

---

## Порядок работы

1. Определить **размер на сайте** (CSS / слой Figma).
2. Экспортировать из Figma **не больше 2×** этого размера (@1x / @2x — по retina).
3. Сохранить в `img/` с понятным именем.
4. **Проверить размер файла** на диске.
5. Если **> 500 КБ** — сжать до лимита (качество, pngquant и т.п.); **px не уменьшать**, если экспорт уже был ≤ 2× от сайта.
6. Повторно проверить — только потом подключать в HTML/CSS.

---

## Проверка (терминал)

```bash
# один файл
ls -lh img/hero.jpg

# все png/jpg/jpeg в папке
find img -type f \( -iname '*.png' -o -iname '*.jpg' -o -iname '*.jpeg' \) -exec ls -lh {} \;
```

---

## Чек-лист перед сдачей

- [ ] Экспорт из Figma: px **не больше 2×** от размера на сайте
- [ ] Каждый `.png` / `.jpg` / `.jpeg` в `img/` ≤ 500 КБ
- [ ] SVG-иконки и логотипы — без лимита веса
- [ ] Визуал после сжатия совпадает с макетом (нет заметной «мыла» без согласования)
