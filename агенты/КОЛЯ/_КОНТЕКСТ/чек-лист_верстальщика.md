# Чек-лист верстальщика (Sheer)

**Источник:** [Google Docs — Чек-лист верстальщика](https://docs.google.com/document/d/11ba7tZWpTh9AT6W7o4LAbFqt0kmSfdk2HSMrtRK6Vjg/edit)

Использовать **перед сдачей** каждой вёрстки @коля. Пункты с 🤖 — можно делегировать ИИ/автоматизации.

**Примечание для статических лендингов** (`туроператор/` и аналоги): блоки про Contact Form 7, `.scss`, пагинацию статей — только если это в ТЗ (WordPress/Bitrix). Остальное — обязательно или по макету.

---

## 1. Верстка текста

- [ ] Контейнер для текста (более 4 строк) — `.article` (или класс из ТЗ).
- [ ] Заголовки страниц/разделов — семантика `h1`–`h6`.
- [ ] `h1` — **один** на странице (основной заголовок).
- [ ] Пагинатор: `rel="prev"` и `rel="next"` (если есть).
- [ ] Хлебные крошки — разметка [schema.org/BreadcrumbList](https://schema.org/BreadcrumbList) (если есть).
- [ ] Внешние ссылки (не tel/mailto внутренние) — `rel="nofollow"` где требует ТЗ.
- [ ] В `.article` прописаны стили для: `p`, `ul`, `ol`, `li`, `blockquote`, `table`, `a`, `strong`, `img` (по дизайну).

---

## 2. Верстка форм

- [ ] **Разметка по эталону Артэк:** `<form>` без BEM-классов; каждое поле в `.item-form`; сетка — `row` / `col-*`; см. `формы-разметка.md`.
- [ ] Кнопка отправки — `<input type="submit">` или `<button type="submit">` с общим классом (`.btn-main`).
- [ ] У форм **нет** `id` на `<form>`; обёртка с `id` при необходимости.
- [ ] Contact Form 7 — разметка по ТЗ интеграции (только WP-проекты).
- [ ] Телефон: маска `+7 (999) 999-99-99`, `type="tel"`, `inputmode="numeric"`.
- [ ] Поля на mobile: `font-size` ≥ **16px** (iOS без зума).

---

## 3. Верстка блоков

- [ ] **Figma → img/:** экспорт **не больше 2×** от размера картинки на сайте (CSS / слой макета); см. `figma-изображения-500kb.md`.
- [ ] **Карта контактов:** Яндекс.Карта API (`#map`), не скрин `map.png`; см. `yandex-karta.md`.
- [ ] Изображения: `max-width: 100%`, `object-fit` / пропорции без искажений.
- [ ] **Figma → img/:** каждый файл **PNG, JPG, JPEG** — **не более 500 КБ**; при превышении — сжать до лимита; SVG и прочие форматы — без лимита (см. `figma-изображения-500kb.md`).
- [ ] **Bootstrap-сетка обязательна:** `container` / `container-fluid` + `row` + `col-*` во всех секциях (не flex/grid вместо Bootstrap); **без `gap` на `.row`**; **без** лишних gutter/calc на `.col-*` без явного ТЗ (см. `примеры/2026-05-20_bootstrap_без_лишних_col.md`).
- [ ] Ховеры по макету или согласованы; везде `transition`.
- [ ] Одинаковые блоки/кнопки — **общие классы** (`.btn-main`, `.item-*`).
- [ ] Карточки товара/новости/статьи: **отдельные ссылки** на изображение и название; CTA («Заказать», «Читать») — не внутри общей ссылки карточки (см. `примеры/2026-05-20_ссылки_карточки_название_изображение.md`).
- [ ] Межстраничная пагинация — по эталону [sheer82.ru](https://sheer82.ru/vse-stati/page/2/) (если в ТЗ).

---

## 4. Интерактив

- [ ] Слайдеры/карусели — **Slick Slider**.
- [ ] jQuery (в ТЗ Sheer — не выше 3.5.1; в учебных проектах часто 3.6 — сверить с ТЗ).
- [ ] Анимации появления — `animate.css` + `wow.js` (если в макете).
- [ ] Модалки — **Fancybox** (в референсах Fancybox 3).
- [ ] Табы — паттерн из `reference/Артэк` (не дублировать логику).
- [ ] Маска телефона — jquery.mask / maskedinput.
- [ ] Плавный скролл к якорям — `animate` 500 ms, offset header (`getAnchorOffset`).
- [ ] «Заказать звонок» — модалка `#modal-callback`, не якорь на форму.

---

## 5. Общие требования

- [ ] Скрипты на jQuery в `js/common.js`.
- [ ] Минимум лишних библиотек.
- [ ] Меню — паттерн fixed header + mobile (zarina / sport-iv по ТЗ).
- [ ] JS и CSS **не** минифицировать без запроса (отдельные файлы, `?ver=`).
- [ ] Стили: `.scss` — **только если в ТЗ**; иначе `main.css` + `media.css` + `fonts.css`.
- [ ] Иконки — SVG или Font Awesome.
- [ ] 🤖 Шрифты: woff2/woff, `fonts.css`; Google Fonts — по макету.
- [ ] Растровые из Figma (PNG, JPG, JPEG): **≤ 500 КБ** на файл — обязательно, не только TinyPNG «по возможности» (см. `figma-изображения-500kb.md`).
- [ ] Яндекс.Карты через API; **отключить scrollZoom** колесом; блок контактов — **не** `map.png`, а `#map` + API 2.1 (см. `yandex-karta.md`).
- [ ] Футер прижат к низу (sticky footer при короткой странице).
- [ ] Ховер иконок в преимуществах (если в дизайне).
- [ ] Слайдер: автопрокрутка 5 с + стрелки (если в ТЗ).
- [ ] Соцсети: `target="_blank"`.
- [ ] Email: `mailto:`.
- [ ] Все JS в конце `body`.
- [ ] Базовый цвет ссылок из макета.

---

## 6. Мобильная версия

- [ ] Телефон: `tel:` + иконка `fa-phone` в шапке на узком экране.
- [ ] Мобильное меню с запасом под новые пункты.
- [ ] Input ≥ 16px на mobile.
- [ ] Карта не на весь экран на mobile.
- [ ] Retina/SVG для иконок.
- [ ] Крупные зоны нажатия, отступы.
- [ ] &lt; 1024px: скрыты лишние элементы (по согласованию с ТЗ).
- [ ] В слайдерах на mobile — **dots** вместо стрелок (Slick responsive).
- [ ] 🤖 Проверка iOS / Android.
- [ ] Картинки не вылезают из контейнера.
- [ ] **Agro-As:** прогнать `примеры/2026-05-28_Agro-As_адаптив_viewport.md` (1024×640, billbord не под header, wholesale 993–1599).

## 7. Тестирование

- [ ] 🤖 Валидность HTML/CSS (W3C).
- [ ] Desktop / tablet / mobile.

- [ ] Слайдеры, модалки, табы, формы, якоря.
- [ ] 🤖 Lighthouse / PageSpeed.
- [ ] 🤖 Accessibility (Lighthouse / Axe).
