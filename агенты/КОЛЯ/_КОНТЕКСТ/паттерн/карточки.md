## Новости — отдельные ссылки (фото + заголовок)

**Правило:** на карточке новости/товара в каталоге — **две ссылки**. На документе/сертификате — **одна** (скачивание).

```html
<article class="item-news">
  <a href="article.html" class="item-news__image">
    <img src="img/news1.jpg" alt="">
  </a>
  <div class="item-news__content">
    <a href="article.html" class="item-news__title">Заголовок новости</a>
    <p class="item-news__text">Краткое описание…</p>
    <div class="item-news__bottom">
      <span class="item-news__date">12.05.2026</span>
      <a href="article.html" class="btn-main btn-main--news">Читать</a>
    </div>
  </div>
</article>
```

Сетка: `col-lg-4 col-md-6`.

## Сертификаты / документы — одна ссылка

```html
<a href="files/cert.pdf" class="item-certificate" target="_blank" rel="noopener">
  <span class="item-certificate__image">
    <img src="img/cert-preview.jpg" alt="Название">
  </span>
  <span class="item-certificate__title">Название документа</span>
  <span class="item-certificate__btn" aria-hidden="true">
    <img src="img/icon-download.svg" alt="">
  </span>
</a>
```

Сетка: `col-lg-3 col-md-6`. Страница: шаблон «Сертификаты», ACF repeater `sertifikaty`.

## WP — карточка в цикле

```php
<div class="col-lg-3 col-md-6 certificates-page__col">
  <?php
  set_query_var( 'certificate_card', array(
    'url'   => $file_url,
    'title' => $title,
    'image' => $image,
  ) );
  get_template_part( 'template-parts/certificates/card' );
  ?>
</div>
```

## Фильтр каталога на mobile (WithLove)

```html
<button type="button" class="btn-main btn-main_filter d-lg-none">
  <span>Фильтр</span>
  <img src="img/icon-filter.svg" alt="">
</button>
```

Показывать только `< 992px`, сайдбар — slideToggle по клику.
