# Паттерны вёрстки — @коля

**Главный источник кода.** Не искать `reference/` и старые проекты — сначала эта папка.

## Как пользоваться

1. Перед задачей — открыть ближайший файл по теме.
2. Скопировать HTML/CSS/JS, адаптировать под макет (классы не менять без причины).
3. **Новый устойчивый паттерн** после сдачи задачи — сразу дописать сюда (новый файл или раздел) + строка в таблицу ниже.
