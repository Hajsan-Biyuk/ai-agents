# Паттерн: адаптив media.css

**Когда:** любые правки адаптива Agro-As и аналогов  
**Источник:** Agro-As/maintheme/css/media.css  
**Обновлено:** 2026-06-05

## Правило

1. Все `@media` — **только** в `media.css`
2. Один блок на диапазон, порядок: max-width сверху → min-width в конце
3. После правок — bump `?ver=` в `header.php`
4. **Критично:** `.billbord__spacer` — отступ под fixed header, не обнулять

## billbord + fixed header

| Условие | `.billbord__spacer` | `.billbord` padding-top |
|---------|---------------------|-------------------------|
| Desktop main.css | 134px | 25px |
| ≤1400px | 118px | 0 |
| ≤1200px | 110px | 0 |
| 993–1024px | 80px | 0 |

**Ошибка:** spacer = 0 + маленький padding-top → контент под шапкой.

## Целевые viewport (проверять)

| Viewport | Роль |
|----------|------|
| 1920×1080 | Полный desktop |
| 1400–1599 | Компактный desktop |
| 993–1024 | Burger, каталог 2 col |
| 1024×640 | Низкая высота, hero компактный |
| ≤992 | Мобилка |
| 768–992 | Планшет (−20% UI) |

## Компакт −20% (ноутбуки и планшеты)

Папка правил в конце `media.css`, блоки:

- `1025–1599px` — UI, header, footer
- `993–1024px` — компактный desktop
- `768–992px` — планшет

**Не трогать:** `.billbord__title`, `.title-section` (секционные заголовки).

## Галерея товара — max-height desktop

```css
@media (min-width: 1200px) {
  .product-page__gallery img,
  .product-page__gallery-link img {
    max-height: 570px;
  }
}
```

## Каталог sticky

Sticky сайдбар и buy-col — с **1025px** (`min-width: 1200px` в конце файла).
