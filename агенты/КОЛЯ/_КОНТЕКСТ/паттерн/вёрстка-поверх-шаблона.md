# Вёрстка поверх чужого шаблона CMS (без Bootstrap)

Когда новые шапка/подвал/страница встают на живой сайт со старым CSS (Аспро, чужая тема). Эталон: `Laminarium/redesign/html/` (2026-11-18).

## Изоляция CSS

- Префикс классов (`lam-`), всё внутри обёрток `.lam-header`, `.lam-home`, `.lam-footer`. Никаких `*`, `body`, `a`, `h1` без обёртки.
- Нормализация: `:is(.lam-header,.lam-home,.lam-footer) a {…}` — специфичность (0,1,1), ниже компонентов.
- Компоненты: `.lam-home .lam-card__name` (0,2,0) — перебивает `a:hover`, `input[type="email"]` шаблона.
- Сбросить у кнопок `text-transform`, `outline: none` шаблона; вернуть `:focus-visible`.
- Шрифты под своими именами (`LamInter`), чтобы не столкнуться с `@font-face` шаблона.
- Свой CSS подключать после CSS шаблона.

## Мобильная шапка без дублей разметки

Десктоп — два flex-ряда. ≤1199: контейнер `display: grid`, ряды/группы `display: contents`, нужные элементы (лого, телефон, корзина, бургер, поиск) ставятся `grid-row/grid-column`, остальное (`order` + `grid-column: 1 / -1`) показывается по `.is-open`. Счётчик корзины остаётся в одном экземпляре.

## Карусель без библиотек

`.lam-track` — `display:flex; overflow-x:auto; scroll-snap-type:x mandatory; position:relative` (иначе абсолютные визуально-скрытые span внутри растягивают документ), `padding`+отрицательный `margin` под тени карточек. Стрелки `[data-lam-prev]/[data-lam-next]` в корне `[data-lam-carousel]`, листают видимый трек (`offsetParent !== null`) на ширину карточки + gap. JS — `Laminarium/redesign/html/js/lam.js`.
