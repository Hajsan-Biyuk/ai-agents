# Паттерн: общая структура страницы

**Когда:** любой новый HTML-файл или секция темы  
**Источник:** zarina 3, Agro-As  
**Обновлено:** 2026-06-05

## Правило

- `main.css` — без `@media`
- `media.css` — только media queries, один блок на диапазон
- Bootstrap: `bootstrap-grid.css`, **без `gap` на `.row`**
- Версии: `main.css?ver=` / `media.css?ver=` — bump после правок CSS

## HTML `<head>`

```html
<meta charset="utf-8" />
<title>Заголовок</title>
<meta http-equiv="X-UA-Compatible" content="IE=edge" />
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">
<meta name="format-detection" content="telephone=no" />
<link rel="stylesheet" href="libs/bootstrap/bootstrap-grid.css" />
<link rel="stylesheet" href="libs/fontawesome-free-5.12.0-web/css/all.min.css" />
<link rel="stylesheet" href="libs/fancybox-master/dist/jquery.fancybox.min.css" />
<link rel="stylesheet" href="libs/slick-1.5.9/slick/slick.css" />
<link rel="stylesheet" href="css/fonts.css?ver=1.0" />
<link rel="stylesheet" href="css/main.css?ver=1.0" />
<link rel="stylesheet" href="css/media.css?ver=1.0" />
```

## DRY-классы (не плодить секционные копии)

| Тип | Классы |
|-----|--------|
| Кнопки | `.btn-main`, `.btn-main--yellow`, `.btn-main--dark` |
| Заголовки | `.title-section`, `.title-small` |
| Текст | `.descr-section` |
| Шапка секции | `.head-section` |
| Формы | `.item-form`, `.checkbox` |
| Модалки | `.modal-block`, `.modal-wrap` |

## Bootstrap-сетка (Agro-As)

```html
<div class="container-fluid container-main">
  <div class="row">
    <div class="col-lg-4 col-md-6">…</div>
  </div>
</div>
```

## Крошки (внутренние страницы WP)

```html
<nav class="breadcrumbs" aria-label="Хлебные крошки">
  <a href="/">Главная</a>
  <span class="breadcrumbs__sep">/</span>
  <span class="breadcrumbs__current">Заголовок</span>
</nav>
```
