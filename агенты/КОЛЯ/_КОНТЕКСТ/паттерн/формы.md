# Паттерн: формы

**Когда:** модалки, секции, страницы контактов  
**Источник:** Артэк, Agro-As  
**Обновлено:** 2026-06-05

## Правило

Внутри `<form>` — только `.item-form`, Bootstrap `row`/`col-*`, `.checkbox`, `.btn-main`.  
BEM секции (`.contacts-page__card`) — **снаружи** `<form>`.

## HTML — модалка

```html
<form>
  <div class="item-form">
    <input type="text" placeholder="Ваше имя" required>
  </div>
  <div class="item-form">
    <input type="tel" placeholder="Номер телефона" class="input-phone" inputmode="numeric" required>
  </div>
  <input type="submit" class="btn-main" value="Отправить">
  <div class="checkbox">
    <label>
      <input type="checkbox" required checked>
      <span>Я согласен с условиями обработки персональных данных</span>
    </label>
  </div>
</form>
```

## HTML — форма в секции (2 колонки)

```html
<form action="#" method="post">
  <div class="row align-items-stretch">
    <div class="col-12 col-md-6">
      <div class="item-form">
        <input type="text" name="name" placeholder="Имя" required>
      </div>
    </div>
    <div class="col-12 col-md-6">
      <div class="item-form item-form--message">
        <textarea name="message" placeholder="Сообщение" required></textarea>
      </div>
    </div>
  </div>
  <div class="row align-items-start">
    <div class="col-12 col-lg">
      <div class="checkbox">…</div>
    </div>
    <div class="col-12 col-lg-auto">
      <button type="submit" class="btn-main btn-main--yellow">Отправить</button>
    </div>
  </div>
</form>
```

## CSS — чекбокс (Font Awesome 5 Pro)

Перед вёрсткой проверить в `all.min.css`: Pro или Free.

```css
.checkbox label span::after {
  content: '\f00c';
  font-family: 'Font Awesome 5 Pro';
  font-weight: 400;
  font-size: 11px;
  color: #052d24;
  opacity: 0;
}
.checkbox label input:checked + span::after {
  opacity: 1;
}
```

**Запрещено:** `'Font Awesome 5 Free'` + `font-weight: 900`, если в libs подключён Pro.

## Планшет

Поля форм **16px** на 768–992px (iOS без зума).
