# Паттерн: модалки Fancybox

**Когда:** «Заказать звонок», заявки, галерея lightbox  
**Источник:** Артэк  
**Обновлено:** 2026-06-05

## Правило

- Ссылка: `href="#modal-callback"` + класс `fancybox`
- Разметка модалки — в `footer` (или `footer.php`), **вне** `.wrapper`
- Fancybox без сдвига страницы: `scrollbar-gutter: stable`

## HTML — триггер

```html
<a href="#modal-callback" class="link-main fancybox">заказать звонок</a>
```

## HTML — модалка

```html
<div id="modal-callback" class="modal-block">
  <div class="modal-wrap">
    <div class="title-section">Закажите звонок</div>
    <div class="descr-modal">и наш менеджер свяжется с вами в течение 30 минут</div>
    <form>
      <div class="item-form">
        <input type="text" placeholder="Ваше имя" required>
      </div>
      <div class="item-form">
        <input type="tel" placeholder="Номер телефона" class="input-phone" inputmode="numeric" required>
      </div>
      <input type="submit" class="btn-main" value="Отправить">
      <div class="checkbox">
        <label>
          <input type="checkbox" required checked>
          <span>Я согласен с условиями обработки персональных данных</span>
        </label>
      </div>
    </form>
  </div>
</div>
```

## CSS

```css
html {
  scrollbar-gutter: stable;
}
.modal-block {
  display: none;
  padding: 0;
  background: transparent;
}
```

## JS — Fancybox init

```javascript
$('.fancybox').fancybox({
  hideScrollbar: false,
  touch: false,
  autoFocus: false,
  backFocus: false
});
```
