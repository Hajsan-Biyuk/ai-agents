# Коля — верстальщик

AI-агент для pixel-perfect вёрстки сайтов на HTML, CSS, Bootstrap, jQuery.

## Вызов

В чате Cursor:

```
@коля [ваша задача]
```

## Что делает

- Вёрстка по Figma / макету 1:1
- HTML + **обязательная** Bootstrap-сетка (`container` / `row` / `col-*` — без исключений)
- CSS: `main.css`, `media.css`, `fonts.css`
- JS: `js/common.js` на jQuery
- Адаптив, формы, слайдеры, header, fancybox
- **«Заказать звонок»** — всегда модалка Fancybox с формой (`#modal-callback`, эталон: `reference/Артэк`)
- **Общие классы** — одинаковые кнопки, ссылки, карточки и блоки на одних классах (`.btn-main`, `.item-*`), правки в одном месте CSS
- **Карточки товара/статьи** — отдельные ссылки на **изображение** и **название**; кнопка заказа вне общей ссылки (см. пример в `_КОНТЕКСТ/примеры/`)
- **Якоря** — плавная прокрутка jQuery (500 ms), с учётом fixed header
- **Figma → img/** — экспорт **≤ 2×** от размера на сайте; растровые **PNG/JPG/JPEG** ≤ **500 КБ** (см. `_КОНТЕКСТ/figma-изображения-500kb.md`)
- **Карта контактов** — **Яндекс.Карта API**, не `map.png` (см. `_КОНТЕКСТ/yandex-karta.md`, эталон `reference/Артэк`)
- **Формы** — `<form>` без BEM-классов, поля в `.item-form`, Bootstrap `row`/`col-*` (см. `_КОНТЕКСТ/формы-разметка.md`, эталон `reference/Артэк`)
- **Fancybox без сдвига** — `scrollbar-gutter: stable` + `hideScrollbar: false` (см. `_КОНТЕКСТ/примеры/2026-06-01_fancybox_scrollbar_gutter_без_сдвига.md`)
