# Berega: −20% компактность на планшетах и ноутбуках

**Дата:** 2026-06-04  
**Файл:** `local/templates/berega/css/media.css`

## Диапазоны

| Viewport | Что меняется |
|----------|----------------|
| **993–1919px** | Ноутбуки: `--brg-section-y` 50→40, hero 50→40, заголовки ×0.8 |
| **768–992px** | Планшеты: `--brg-section-y` 32→26 (поверх mobile-токенов) |
| **≤767px, ≥1920px** | Без изменений |
| **768–992 формы** | Поля **16px** / height 60px — iOS без зума |

## UI ×0.8 (768–1919)

Отступ `.page`, `.btn-main`, `.scenario-screen__*`, карточки factor/zk/deal/about, компактные `#invest` / `#location` / `#deal` / `#dev`.

Заголовки секций принудительно через `--brg-h-*` поверх локальных px в брейкпоинтах 1200/1280.

## Текст −20% (768–1919), min 14px

- Токены `--brg-font-base` … `--brg-font-2xl`, база `.page { font-size: 14px }`
- ~125 селекторов body/UI из `main.css`
- **Не трогали:** `--brg-h-*`, секционные title, header, footer
- **768–992:** поля форм **16px** (перебивают 14px)

## Не трогали

Header, footer, телефоны ≤767px, large desktop ≥1920px.
