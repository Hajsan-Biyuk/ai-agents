# Berega: типографика −20% и унификация заголовков

**Дата:** 2026-06-04  
**Файлы:** `local/templates/berega/css/main.css`, `media.css`

## Задача

- Уменьшить **весь текст** сайта на ~20% (`×0.8`, округление **вверх** до целого px).
- **Не трогать** header (`.header.default`) и footer (`.site-footer`, `.footer__*`).
- Hero главной на desktop — пропорционально (52→42px, 24→20px).
- Сверить заголовки: единые `line-height` / `letter-spacing`.

## Реализация

1. Скрипт по `font-size` в правилах CSS (кроме селекторов header/footer): px и clamp/vw; отдельный проход для `font-size:NNpx` без пробела перед следующим свойством.
2. Header/footer вручную возвращены к исходным px (скрипт внутри `@media` сначала ошибочно их трогал).
2. `:root` — токены `--brg-font-base: 13px`, `--brg-font-hero-title: 42px`, `--brg-font-section: 32px`, `--brg-line-title: 1.3`, `--brg-line-lead: 1.4`.
3. `.page { font-size: var(--brg-font-base); }` — база для наследуемого текста.
4. Блок унификации заголовков секций (`.title-section`, `.zk-section__title`, hero, yk, article h1/h2…).
5. **Исключение iOS:** поля форм на ≤992px — `font-size: 16px` (не 13px), чтобы не было зума при фокусе.
