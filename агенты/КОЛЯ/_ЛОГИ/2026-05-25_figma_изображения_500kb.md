# 2026-05-25 — Лимит 500 КБ для растровых из Figma

## Правило

При экспорте из Figma в `img/`:

| Формат | Лимит |
|--------|-------|
| PNG, JPG, JPEG | ≤ **500 КБ** на файл |
| SVG и прочее | без лимита |
