# 2026-06-04 — Berega: единый ритм отступов между секциями

## Задача

На всех страницах `Berega/berega.ru` выровнять вертикальные отступы между секциями: одинаковые сверху и снизу, корректно на всех брейкпоинтах.

## Решение

**CSS-переменные** на `.page`:
- `--brg-section-y` — основной блок (50px desktop → 32px ≤992 → 24px ≤640)
- `--brg-section-y-hero` — низ hero-секций
- `--brg-section-y-catalog-hero` — низ каталожного hero

**Паттерн стыковки** (как `.yk-section + .yk-section`): у соседних секций `padding-top: 0`, зазор = `padding-bottom` предыдущей (без удвоения).

**Файлы:**
- `local/templates/berega/css/main.css` — блок «Единый ритм», сняты разрозненные `padding` у `*-screen`, каталогов, about, zk (компактные id — симметричные пары)
- `local/templates/berega/css/media.css` — переменные на брейкпоинтах, убраны локальные асимметричные override

**Охват:** главная (include-секции), about, каталоги objects/developer/hoteliers, zk-объект, yk/zs-лендинги, статьи/контакты/новости.

## Проверка

- Desktop 1920 / 1366 / 1200
- Tablet 1024 / 992
- Mobile 768 / 640 / 560

Статика: обновлён `?v=20260604` на `main.css` / `media.css`. Bitrix: `header.php` уже `time()`.

## Доп. фикс (главная)

Между `.gray-section-wrap` и `.scenario-screen` не было зазора: `founder-screen` внутри обёртки (не `main > section`), у формы обнулялся `padding-top`. Добавлено `.page main .gray-section-wrap > section` и стык `section + section` внутри обёртки.
