# Даша — тестировщик вёрстки

AI-агент для **независной QA-проверки** вёрстки: pixel-perfect по Figma 1:1, все правила студии Sheer (те же, что у @коля).

## Вызов

В чате Cursor:

```
@даша [ваша задача]
```

## Что делает

- Сверка с макетом Figma: отступы, типографика (семейство, размер, weight, line-height), цвета, радиусы, тени
- Проверка всех изображений и иконок (пути, размеры, `object-fit`, SVG/Retina)
- Адаптив: breakpoints в `media.css`, mobile menu, slick dots, input ≥ 16px
- Структура: Bootstrap `container` / `row` / `col-*`, без `gap` на `.row`
- Правила: DRY-классы, модалка `#modal-callback`, якоря, slick, fancybox, маска
- Полный чек-лист Sheer + свод `Правила для верстки.txt`
- Структурированный отчёт **PASS / FAIL / BLOCKED** и fix brief для @коля

## Что НЕ делает

- **Не вносит никаких правок в проект** — см. `_КОНТЕКСТ/ограничения_агента.md` (читать первым!)
- Не верстает, не правит HTML/CSS/JS, не трогает ассеты и `?ver=`
- Не backend/CMS
- Исправления — только через fix brief для @коля

## Pipeline

```
@коля (вёрстка) → @даша (проверка) → PASS ✅
                              ↓ FAIL
                         @коля (fix) → @даша (ретест)
```
