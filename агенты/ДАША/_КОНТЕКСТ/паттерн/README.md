# Паттерны проверки — @даша

**Эталоны «как должно быть в коде»** для PASS/FAIL. Код не править — только сверять.

## Как пользоваться

1. Открыть паттерн по теме проверки.
2. Сверить с макетом Figma (`протокол_figma.md`).
3. Расхождение с паттерном = FAIL в отчёте + fix brief для @коля.
