# Паттерн: сверка кода с эталоном

**Когда:** QA любой страницы Agro-As и аналогов  
**Обновлено:** 2026-06-05

## Правило

FAIL, если код **не совпадает** с паттерном @коля, даже если «визуально похоже».

## Чеклист быстрой сверки

### Структура

- [ ] `css/main.css` без `@media`
- [ ] Bootstrap grid, **нет `gap` на `.row`**
- [ ] DRY: `.btn-main`, `.title-section`, не `.about__btn`
- [ ] `container-fluid container-main` на внутренних

### Формы

- [ ] Внутри `<form>` только `.item-form`, `.checkbox`, `.btn-main`
- [ ] Чекбокс: `label` → `input` + `span`
- [ ] FA Pro в `::after`, не Free + 900
- [ ] Input ≥ 16px на mobile

### Модалки

- [ ] `href="#modal-callback"` + `fancybox`
- [ ] `#modal-callback` в footer, вне wrapper
- [ ] `html { scrollbar-gutter: stable }`

### Карточки

- [ ] Новости: **две** ссылки (image + title)
- [ ] Сертификаты: **одна** ссылка на файл
- [ ] Документ: `.item-certificate__btn` с иконкой

### Адаптив

- [ ] `.billbord__spacer` не 0 на tablet/desktop
- [ ] Каталог sticky с 1025px
- [ ] Burger ≤1024, не ломает hero под header

### Карта

- [ ] `#map` + `data-lat/lng`, не `map.png`
- [ ] API 2.1 перед `common.js`

## Правильно / неправильно

### Крошки

```html
<!-- PASS -->
<nav class="breadcrumbs" aria-label="Хлебные крошки">
  <a href="/">Главная</a>
  <span class="breadcrumbs__sep">/</span>
  <span class="breadcrumbs__current">Новости</span>
</nav>

<!-- FAIL -->
<ul class="breadcrumbs"><li>…</li></ul>
```

### Форма

```html
<!-- FAIL — BEM внутри form -->
<form class="contacts-page__form">
  <div class="contacts-page__field">…</div>
</form>

<!-- PASS -->
<form>
  <div class="item-form">…</div>
</form>
```

## Отчёт

Формат: `PASS` / `FAIL` / `BLOCKED` + путь к файлу + ожидание из паттерна + факт в коде.
