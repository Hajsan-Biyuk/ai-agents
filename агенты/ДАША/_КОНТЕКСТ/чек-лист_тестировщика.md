## B. Pixel-perfect vs Figma (каждая секция в scope)

### B.1. Геометрия и отступы
- [ ] Ширина контейнера / max-width (напр. 1920, padding 160 → контент 1600).
- [ ] Высота блоков, min-height, aspect-ratio.
- [ ] padding / margin каждой секции (top, right, bottom, left).
- [ ] gap **между** элементами внутри flex-колонки (не на `.row`!).
- [ ] Выравнивание: flex align/justify, vertical-align текста с иконкой.

### B.2. Типографика (не пропускать «мелочи»)
- [ ] font-family — правильное начертание из `fonts.css`.
- [ ] font-size (px).
- [ ] font-weight (400/500/600/700…).
- [ ] line-height (px или безразмерный — как в макете).
- [ ] letter-spacing (если в макете ≠ 0).
- [ ] color (#hex / rgba).
- [ ] text-transform, text-decoration.
- [ ] Количество строк / обрезка (ellipsis) — если в макете.

### B.2.1. Подключение шрифтов (ОБЯЗАТЕЛЬНО на каждой проверке)

> Без этого блока проверка font-weight **недействительна** — браузер покажет Arial + synthetic bold.

- [ ] Папка `fonts/` с woff2; пути в `fonts.css` относительные (`../fonts/…`).
- [ ] Каждый URL из `@font-face` — **HTTP 200** (`curl -sI` или DevTools → Network).
- [ ] Нет битых CDN-ссылок (устаревшие версии gstatic).
- [ ] Веса в `@font-face` покрывают все `font-weight` из макета (400–800).
- [ ] DevTools → Computed: hero h1, `.title-section`, `.btn-main` → `font-family: Manrope` (не Arial).
- [ ] Таблица «элемент → Figma weight → CSS weight» в отчёте для ключевых блоков.

**404 на woff2 = Critical → VERDICT: FAIL.**

### B.3. Цвета и эффекты
- [ ] background-color, gradient, opacity overlay.
- [ ] border: width, style, color, radius.
- [ ] box-shadow (offset, blur, spread, color).
- [ ] backdrop-filter / blur (если в макете).

### B.4. Изображения и иконки
- [ ] Файл есть в `img/`, путь относительный, нет 404.
- [ ] Размеры отображения (width/height) vs макет.
- [ ] `object-fit`: contain / cover — по макету (Agro-As: product **contain**).
- [ ] border-radius на фото.
- [ ] SVG: viewBox, stroke/fill, размер.
- [ ] Font Awesome: правильный класс, размер, цвет, hover.
- [ ] Retina: не размыто на 2x (по возможности).

### B.5. Состояния
- [ ] :hover — цвет, фон, border, transform, shadow.
- [ ] :focus / :active — кнопки, ссылки, поля.
- [ ] :disabled — если в макете.
- [ ] `transition` на интерактивных элементах.

## J. Вердикт

| Результат | Условие |
|-----------|---------|
| **PASS** | Нет Critical/Major по Figma и правилам; Minor — только с согласия пользователя |
| **FAIL** | Любое Critical/Major → Kolya fix brief |
| **BLOCKED** | Нет макета / неясный scope / Figma rate limit без кэша |

**Severity:**
- **Critical** — визуал 1:1, сломанный интерактив, нет модалки callback, gap на .row, нет Bootstrap-сетки.
- **Major** — адаптив ломается, неверный шрифт/weight, 404 ассетов.
- **Minor** — 1px погрешность по согласованию, некритичный комментарий в коде.
