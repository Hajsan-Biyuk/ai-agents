## reference/zarina-wp — эталон без WooCommerce

**Путь:** `reference/zarina-wp/maintheme/`  
**Тип:** сайт отеля, CPT `catalog`, блог  
**CMS:** WordPress + ACF + Contact Form 7  
**Тема:** `maintheme`

### Отличия от natyajka

| | natyajka | zarina-wp |
|---|----------|-----------|
| WooCommerce | да | нет |
| CPT | service | catalog |
| Формы | кастом / AJAX | CF7 shortcode в модалках |
| datetimepicker | нет | да (бронирование) |
| Yandex Maps | нет | inline в footer.php |

### Структура (ключевое)

| Путь | Назначение |
|------|------------|
| `header.php` | Libs CSS, ACF контакты, menu-mobile |
| `footer.php` | Модалки CF7, cookies, jQuery + libs + common.js |
| `front-page.php` | Баннер ACF, форма бронирования, каталог CPT |
| `page-about.php` | Template Name: Об отеле |
| `page-numbers.php` | Номера |
| `page-infrastructure.php` | Инфраструктура |
| `page-contacts.php` | Контакты + карта |
| `page-blog.php` | Блог |
| `single-catalog.php` | Карточка номера |
| `single-post.php` | Статья |
| `template-parts/sect_form.php` | Переиспользуемая секция формы |

### ACF Options (zarina-wp)

- `adres`, `polnyj_adres`, `telefon`
- `telegram`, `max`

## reference/natyajka — ГЛАВНЫЙ ЭТАЛОН (WooCommerce)

**Путь:** `reference/natyajka/maintheme/`  
**Тип:** интернет-магазин, натяжные потолки  
**CMS:** WordPress + WooCommerce + ACF  
**Тема:** `maintheme`

### Структура темы

| Путь | Назначение |
|------|------------|
| `header.php` | Libs CSS, меню, поиск, избранное, ACF-контакты, marquee |
| `footer.php` | Меню, CPT `service`, ACF, модалки |
| `front-page.php` | Главная |
| `page-*.php` | about, contacts, catalog, basket, blog, services… |
| `functions.php` | WC support, вариации, AJAX PDF, регистрация, хуки |
| `woocommerce/` | Переопределения шаблонов WC |
| `css/` | fonts.css, main.css, media.css |
| `js/common.js` | jQuery: header, slick, fancybox, корзина, вариации |
| `libs/` | bootstrap-grid, fontawesome, fancybox, slick |
| `inc/` | template-tags, customizer, jetpack |

### Подключение стилей (header.php)

Порядок как у Коли в статике:

1. `libs/bootstrap/bootstrap-grid.css`
2. fontawesome → fancybox → slick (+ slick-theme)
3. `css/fonts.css` → `css/main.css?ver=` → `css/media.css?ver=`
4. `<?php wp_head(); ?>`

### Пути к ассетам

```php
<?php bloginfo('template_directory'); ?>/img/logo.svg
```

В функциях:

```php
get_template_directory_uri() . '/js/common.js'
get_template_directory() . '/img/logo.png'
```

### WooCommerce

**Включение:**

```php
add_theme_support('woocommerce');
```

**Ключевые переопределения:**

| Файл | Задача |
|------|--------|
| `woocommerce/content-single-product.php` | Карточка, вариации, кастомный UI |
| `woocommerce/partials/product-card-images.php` | Картинки в листинге |
| `woocommerce/archive-product.php` | Каталог (если переопределён) |
| `woocommerce/cart/`, `checkout/` | Корзина и оформление |

**Кастомные поля вариаций** (Диаметр, Форма, Литраж):

- Хук: `woocommerce_product_after_variable_attributes`
- Сохранение: `woocommerce_save_product_variation`
- Meta: `_maintheme_variation_diameter` и т.д.
- См. `functions.php` ~строки 196–280

**AJAX PDF презентации:**

- `wp_ajax_fv_get_presentation` / `nopriv`
- `fv_generate_product_pdf()` — FPDF

### ACF

| Использование | Пример |
|---------------|--------|
| Options (контакты) | `get_field('телефон', 'option')` |
| Соцсети | `whatsapp`, `telegram`, `max` |
| Страницы | `get_field('поле')` на page template |

Телефон в ссылке:

```php
href="tel:+<?php echo preg_replace("/[^0-9]/", '', get_field('телефон', 'option')); ?>"
```

### JS (common.js)

Сохранять логику из вёрстки Коли:

- header sandwich / `menu-mobile`
- slick, fancybox (`autoFocus: false`)
- вариации товара, корзина AJAX
- маска телефона на `.input-phone`

Подключать **после** jQuery в footer, перед `wp_footer()`.

## Workflow: от вёрстки к теме

```
1. @коля сдаёт: index.html, css/, js/, img/, fonts/, libs/
2. @макс создаёт тему:
   - style.css (Theme Name, Version)
   - Скопировать ассеты в maintheme/
   - header.php / footer.php из HTML
   - Разрезать main на front-page.php + page-*.php
   - functions.php: theme support, меню, WC, ACF
3. Зарегистрировать меню в админке
4. Импорт/создание страниц с нужными шаблонами
5. WooCommerce: категории, товары, переопределения
6. Проверка на стенде
```

## 1C-Bitrix (краткий эталон)

**Папка шаблона:** `local/templates/[имя_сайта]/`

| Статика | Bitrix |
|---------|--------|
| header block | `header.php` + `$APPLICATION->ShowHead()` |
| footer | `footer.php` |
| секция страницы | `index.php` или `sections/` |
| CSS/JS | `template_styles.css`, `script.js` или Asset API |

**Компоненты:** не вставлять весь HTML в `component.php` — вынести в `template.php` шаблона `.default`.

**Классы вёрстки:** те же `.header`, `.btn-main`, Bootstrap grid — не менять.

## MODX (краткий эталон)

| Статика | MODX |
|---------|------|
| header | Чанк `header` |
| footer | Чанк `footer` |
| блок | Чанк + вызов `[[$chunk]]` |
| поля контактов | TV на ресурсе или настройках |

**Шаблон ресурса:** объединяет чанки, подключает CSS/JS из `assets/templates/`.

## Python (утилиты)

| Задача | Подход |
|--------|--------|
| Импорт товаров | CSV → WooCommerce REST API или WP-CLI |
| Замена путей в шаблонах | Скрипт по `maintheme/**/*.php` |
| Парсинг старого сайта | BeautifulSoup / requests → JSON для импорта |

Скрипты хранить в `scripts/` проекта, не в теме WP.
