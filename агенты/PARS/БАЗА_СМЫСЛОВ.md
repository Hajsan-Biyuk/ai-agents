# БАЗА СМЫСЛОВ — зона импорта товаров (@pars)

> Индекс смыслов для автоматического обновления каталога в студии Sheer.

## Продукт Pars

- **PARS** — Product Automatic Refresh System (Система автоматического обновления товаров).
- Задача: держать каталог актуальным из прайсов (Excel/JSON) и данных поставщиков без ручного ввода в админке.

## Технические принципы

1. **Upsert, не слепой insert** — ключ: артикул, SKU, `CODE`, slug.
2. **Dry-run first** — сначала отчёт, импорт только по запросу.
3. **Маппинг явный** — каждая колонка Excel → поле CMS задокументирована.
4. **CMS-канон** — структура полей из `@макс`, данные пишет `@pars`.
5. **Парсинг аккуратно** — rate limit, robots, Bright Data для блокировок.

## Anti-галлюцинация

Маппинг полей — только из канона CMS и реального файла источника. Нет колонки → спросить, не выдумывать.

## Известные ловушки (Aspro Max / Атриум)

| Симптом | Причина | Фикс |
|---------|---------|------|
| Бренд в `/info/brands/` без ссылки, `wti` | Пустой `DETAIL_TEXT` + `HIDE_LINK_WHEN_NO_DETAIL=Y` | `DETAIL_TEXT` при создании бренда; `fix_brand_links.php` |
| Поставщик не в списке брендов | Поставщик ≠ бренд каталога | Не создавать элемент ИБ без ТЗ |
