# Референсы импорта — @pars

Эталонные реализации в репозитории. **Не копировать слепо** — сверять с CMS проекта.

## 1C-Bitrix — Slon каталог

| Файл | Назначение |
|------|------------|
| `Slon/Slon-site/local/php_interface/slon_install_catalog.php` | Класс `SlonInstallCatalog`: IB, секции, свойства, цены, upsert по `CODE` |
| `Slon/Slon-site/local/tools/slon_import_catalog.php` | Web UI: `?dry=1`, `?purge=1` |
| `Slon/Slon-site/local/templates/slon/includes/data/catalog_products.php` | Исходные данные 12 товаров |

**Ключ upsert:** `CODE` (slug элемента)  
**Свойства:** ARTICLE, SIZE, DENSITY, CAPACITY, MATERIAL, MIN_PARTY, MULTIPLICITY, MIN_QTY, PACK_STEP  
**Цены:** BASE, WHOLESALE_500, WHOLESALE_5000

## WordPress — Agro-As

| Файл | Назначение |
|------|------------|
| `Agro-As/maintheme/inc/cpt-product.php` | CPT + taxonomy |
| `Agro-As/maintheme/acf-json/group_agro_as_product.json` | Поля карточки |
| `агенты/МАКС/_КОНТЕКСТ/product-single-wp-pattern.md` | Маппинг ACF → разметка |
| `агенты/МАКС/_КОНТЕКСТ/cpt-wordpress-pattern.md` | Регистрация CPT |

**Ключ upsert:** `post_name` (slug) или meta артикула — уточнить в ТЗ  
**Описание:** `post_content`  
**Галерея, вариации, характеристики:** ACF

## WordPress — WooCommerce (natyajka)

| Путь | Назначение |
|------|------------|
| `reference/natyajka/maintheme/woocommerce/` | Шаблоны |

**Импорт:** WC REST, WP-CLI `wc product create`, CSV WooCommerce
