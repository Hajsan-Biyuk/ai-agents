# Стек Pars — импорт и парсинг товаров

## Python (основной)

| Пакет | Назначение |
|-------|------------|
| `openpyxl` | Чтение `.xlsx` |
| `pandas` | Табличные данные, CSV, сложный Excel |
| `xlrd` | Legacy `.xls` (если нужен) |
| `requests` | HTTP к API, простые страницы |
| `beautifulsoup4` | Разбор HTML после scrape |
| `lxml` | Быстрый парсер для BS4 |
| `python-slugify` / `transliterate` | slug из названия (транслит) |
| `Pillow` | Обработка/валидация изображений |
| `python-dotenv` | Локальные credentials (не коммитить) |

**Установка (локально в проекте):**

```bash
python3 -m venv .venv-pars && source .venv-pars/bin/activate
pip install openpyxl pandas requests beautifulsoup4 lxml python-slugify Pillow python-dotenv
```

## WordPress

| Инструмент | Когда |
|------------|-------|
| WP-CLI | `wp post create`, `wp post meta`, bulk на сервере |
| REST API | `/wp-json/wp/v2/` + Application Passwords |
| PHP-скрипт в теме | Одноразовый импорт через `WP_Query` + `update_field()` |

**Agro-As:** CPT `product`, taxonomy `product_cat`, ACF — см. `import-wp-products.md`.

**WooCommerce:** `wc product create`, meta `_sku`, `_price`, REST `/wc/v3/products`.

## 1C-Bitrix

| Инструмент | Когда |
|------------|-------|
| `CIBlockElement::Add/Update` | Как `SlonInstallCatalog` |
| `CIBlockElement::SetPropertyValuesEx` | Свойства каталога |
| `CPrice::Set` | Цены типов BASE, WHOLESALE_* |
| Web-скрипт `local/tools/` | Ручной запуск с dry-run |

**Эталон:** `Slon/Slon-site/local/php_interface/slon_install_catalog.php`

## Парсинг (Bright Data MCP)

| Задача | Tool |
|--------|------|
| Google/поиск URL | `search_engine` |
| Статическая страница | `scrape_as_markdown`, `scrape_as_html` |
| Несколько URL | `scrape_batch` |
| JS / login | `scraping_browser_*` (Pro) |
| Структура из markdown | `extract` |

См. `паттерн/supplier-parsing.md`.

## Форматы источников

| Формат | Рекомендация |
|--------|--------------|
| `.xlsx` | Лист «Товары», строка 1 — заголовки |
| `.json` | Массив объектов или `{ "products": [...] }` |
| `.csv` | UTF-8, `;` или `,` — определить при чтении |
| PHP-массив | `return [ [...], ... ];` для Bitrix Slon |

## Выходные артефакты

```
project/
├── data/
│   ├── import/           ← исходные Excel/JSON (не секреты)
│   ├── normalized/       ← нормализованный JSON после маппинга
│   └── reports/          ← dry-run отчёты (timestamp)
└── scripts/pars/         ← Python/PHP импортёры проекта
```

Именование отчёта: `YYYY-MM-DD_{project}_{source}_dry-run.json`
