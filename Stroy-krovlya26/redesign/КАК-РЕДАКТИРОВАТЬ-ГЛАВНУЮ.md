# Как редактировать главную страницу

## Тексты, кнопки, фон первого экрана, верхнее меню, подвал
Админка → **Контент → Информация → «Главная страница»** → элемент «Главная страница».
Или на сайте: войти в админку, включить «Режим правки» → внизу справа кнопка **«✎ Редактировать главную»**.

Поля подписаны по блокам:
- **Первый экран** — плашка, заголовок, подзаголовок, плашки-преимущества (каждая отдельной строкой, «Добавить» — ещё строка), строка фактов (жирное выделяется в визуальном редакторе), **фон** (загрузить новое фото ~1920×960), подписи двух кнопок.
- **Форма расчёта** — заголовок.
- **Верхнее меню** — название пункта, в поле «Описание» рядом — ссылка (например, `/aktsii/`). Пустая строка — пункт не выводится.
- **«Почему мы», «Как мы работаем», «Наши объекты»** — заголовки и тексты, подпись кнопки.
- **Каталог** — заголовки блоков и подписи вкладок.
- **SEO-блок** — заголовок (h1 страницы), текст, подписи кнопок и ссылка на прайс.
- **Подвал** — текст об оферте (на всех страницах).

Пустое поле — на сайте показывается текст по умолчанию. После «Сохранить» изменения видны сразу.

## Где ещё правится главная
| Блок | Где |
|---|---|
| Цифры «16 / 1200 / 1500+ / 800+» | Контент → Информация → «Компания в цифрах» |
| Этапы «Как мы работаем»: названия, тексты | Контент → Информация → «Этапы работы» |
| **Картинки этапов** | там же, у элемента поле **«Детальная картинка»** |
| Плитки каталога: названия, подкатегории | Каталог товаров → разделы |
| **Картинки плиток каталога** | раздел каталога → поле **«Детальная картинка»** |
| Бренды | Контент → Информация → «Производители» |
| Товары во вкладках Акции / Рекомендуем / Хит / Новинка | у товара свойство «Наши предложения» |
| Наши объекты | Работы → «Наши объекты» |
| Карточка акции | Контент → «Статьи» с типом «Акция» (последняя по дате) |
| Телефон, почта, адрес | Файлы и папки → `/include/` → tel.php, mail.php, adress.php |
| Меню подвала «Компания / Каталог / Производители» | Структура сайта → меню (bottom, catalog-link, brends) |
