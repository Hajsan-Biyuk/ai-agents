# Как завести вариации товара (покрытие, толщина, цвет, цена)

Вариант товара — это **торговое предложение**: Админка → Контент → Каталоги → «Торговые предложения» (инфоблок 22).

Одно предложение = одно **покрытие** + одна **толщина** + своя **цена** + список **цветов**, которые есть в этом покрытии.

## Добавить вариант
1. Откройте «Торговые предложения» → «Добавить».
2. **Название** — например, «Grand Line Kvinta Uno Drap 0.45».
3. **Выберите товар** (STARTSHOP_LINK) — товар из каталога, к которому относится вариант.
4. **Покрытие** — из списка (Atlas, Drap, Полиэстер…).
5. **Толщина листа** — из списка (0.45 мм, 0.5 мм…).
6. **Цена** (STARTSHOP_PRICE_1) — цена за единицу товара (м², шт. — как в поле «Единица измерения» у товара).
7. **Старая цена** — по желанию, покажется зачёркнутой.
8. **Цвет** — отметьте все цвета, доступные в этом покрытии и толщине. Образцы цветов берутся из справочника «Tsveta» (Контент → Highload-блоки → Tsveta): там название и картинка-образец.
9. Сохраните. На карточке товара вариант появится в течение нескольких минут (кеш).

## Как это видит покупатель
- Кнопки «Покрытие» и «Толщина»; толщины, которых нет у выбранного покрытия, неактивны.
- Кружки цветов — только доступные для выбранного варианта.
- Цена меняется сразу. Кнопка «Заказать» отправляет заявку с выбранным покрытием, толщиной, цветом и ценой (инфоблок «Заказать товар», уведомления — как у остальных заявок).

## Не использовать
Поля «Толщина» (tolshina) и «Покрытие» (pokrytie_1) в торговых предложениях — дубли, они пустые и на сайте не выводятся. Заполняйте **«Покрытие»** и **«Толщина листа»**.
