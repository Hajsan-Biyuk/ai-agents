--------------------------------------------------------------------------------
3.1. Общие правила
--------------------------------------------------------------------------------

  - Один файл js/common.js на jQuery
  - Плагины подключать перед common.js
  - Делегирование $(document).on(...) где уместно
  - Без import/export TypeScript
  - Минимум лишних библиотек


--------------------------------------------------------------------------------
3.2. Header и меню
--------------------------------------------------------------------------------

  - scroll: .header.default → .fixed при scrollTop > 0
  - .sandwich — slideToggle .menu-mobile, .menu-overlay, body.body--menu
  - .menu-overlay — закрыть меню
  - клик по ссылке в .menu-mobile (<992px) — закрыть меню


--------------------------------------------------------------------------------
3.3. Плавный скролл к якорям
--------------------------------------------------------------------------------

  $('a[href^="#"]').on('click', …)
    - пропустить: href="#", .fancybox, .tabs-page a
    - preventDefault
    - animate scrollTop, 500 ms
    - offset: getAnchorOffset() — высота fixed-шапки + gap 16px
      (в default не учитывать лишний padding-top шапки)

  .scroll-up → scrollTop: 0
  .scroll-down → к целевой секции с тем же offset


--------------------------------------------------------------------------------
3.4. Табы
--------------------------------------------------------------------------------

  - .tabs-wrap: текст активного таба в .btn-tab
  - .btn-tab click — slideToggle списка табов
  - .tabs-page li a click — switch .tab-pane-page, active class
  - на mobile после выбора — закрыть список


--------------------------------------------------------------------------------
3.5. Слайдеры (Slick)
--------------------------------------------------------------------------------

  $('.slider-team').slick({
    arrows: true,
    dots: false,
    infinite: true,
    slidesToShow: 4,
    responsive: [
      { breakpoint: 1200, settings: { slidesToShow: 3, arrows: false, dots: true } },
      { breakpoint: 992,  settings: { slidesToShow: 2, arrows: false, dots: true } },
      { breakpoint: 480,  settings: { slidesToShow: 1, arrows: false, dots: true } }
    ]
  });

  Кастомные prevArrow / nextArrow с Font Awesome
  Автопрокрутка 5 сек — только если в ТЗ


--------------------------------------------------------------------------------
3.6. Аккордеоны
--------------------------------------------------------------------------------

  .item-question__head — FAQ: slideToggle, один открыт
  .item-dropdown__head — в табах: slideToggle, один открыт
